Integration By Substitution

Integration by substitution — often called $u$-substitution — is the integration counterpart of the chain rule. When an integrand contains a composite function and its derivative lurking as a factor, you can replace the inner function with a new variable $u$, simplify the integral, evaluate it, and substitute back. The technique works because the chain rule guarantees that $\frac{d}{dx}[F(g(x))] = F'(g(x)) \cdot g'(x)$, so reading that identity right-to-left gives:

$$\int F'(g(x))\, g'(x)\, dx = F(g(x)) + C$$

In practice, you don't need to identify $F$ in advance. You only need to spot a piece of the integrand that, when called $u$, makes everything else collapse neatly.

The substitution rule. If $u = g(x)$ is differentiable and $f$ is continuous on the range of $g$, then:

$$\int f(g(x))\, g'(x)\, dx = \int f(u)\, du$$

Worked example. Evaluate $\displaystyle\int 2x\cos(x^2)\, dx$.

Set $u = x^2$, so $\frac{du}{dx} = 2x$, which means $du = 2x\, dx$. The factor $2x\, dx$ is already present in the integrand, so substitute directly:

$$\int \cos(u)\, du = \sin(u) + C = \sin(x^2) + C$$

Differentiate to verify: $\frac{d}{dx}[\sin(x^2)] = \cos(x^2) \cdot 2x$. ✓

Problem-solving application. The real skill is recognizing which piece to call $u$. A reliable heuristic: look for a function whose derivative (possibly up to a constant) also appears in the integrand.

Consider $\displaystyle\int \frac{3x^2}{1 + x^3}\, dx$. Set $u = 1 + x^3$, so $du = 3x^2\, dx$:

$$\int \frac{du}{u} = \ln|u| + C = \ln|1 + x^3| + C$$

When the derivative is off by a constant factor, adjust: to compute $\displaystyle\int xe^{x^2}\, dx$, set $u = x^2$, $du = 2x\, dx$, so $x\, dx = \tfrac{1}{2}\, du$:

$$\int e^u \cdot \tfrac{1}{2}\, du = \tfrac{1}{2}e^{x^2} + C$$

For definite integrals, convert the limits: if $u = g(x)$, replace $x = a$ with $u = g(a)$ and $x = b$ with $u = g(b)$, then integrate entirely in $u$ without back-substituting. This avoids a common error — mixing $x$-bounds with a $u$-integral.
