收益(Payoff)

终点:从导数到决策

价格—需求应用(price_demand_application)是整本书的自然终点。前面各章建立的工具,包括函数建模、导数、弹性与最优化,在这里汇合成一个完整的决策流程:观测数据 → 建立需求函数 → 计算收益 → 求最优价格。

设需求函数为 $q = D(p)$,其中 $p$ 是单价,$q$ 是需求量。收益为

$$R(p) = p\,D(p).$$

价格弹性定义为

$$E(p) = \frac{p}{D(p)}\,D'(p).$$

收益最大化的一阶条件 $R'(p) = D(p) + pD'(p) = 0$,等价于

$$E(p^*) = -1.$$

也就是说,最优价格出现在需求为单位弹性之处。当 $|E|>1$ 时(富有弹性),降价会增加收益。当 $|E|<1$ 时(缺乏弹性),提价会增加收益。

例题:线性需求

某咖啡店估计 $D(p) = 200 - 20p$(单位:杯/天,$p$ 以元计)。则

$$R(p) = 200p - 20p^2,\qquad R'(p) = 200 - 40p = 0 \Rightarrow p^* = 5.$$

二阶导数 $R''(p) = -40 < 0$,所以这是极大值。此时 $D(5)=100$,$R(5)=500$ 元。验证弹性:$E(5) = \frac{5}{100}\cdot(-20) = -1$,与理论一致。

若每杯成本为 $c = 2$ 元,则目标应改为利润 $\pi(p) = (p-c)D(p)$。令 $\pi'(p)=0$ 得 $p^* = 6$,高于收益最优价。原因是成本使得"多卖一杯"不再免费。

与各应用领域的联系

本节没有列出具体的下游应用领域,所以这里只说明同一框架可以迁移的方向,请读者自行对照:

  • 经济学与定价:弹性分析是边际分析的直接应用,垄断定价的条件是边际收益等于边际成本。
  • 运营与收益管理:航班、酒店的动态定价,是对不同时段、不同人群分别估计 $D(p)$,再各自求最优。
  • 数据科学:真实的 $D(p)$ 来自回归拟合,例如对数线性模型 $\ln q = a - b\ln p$,其弹性恒为 $-b$。
  • 公共政策:税收改变有效价格,可用弹性估计税负的分担与需求的变化。

    请任选一个方向深入。例如,用一组真实的销售数据拟合对数线性需求模型,估计弹性 $E$,再加入成本,求利润最优价,并检验当 $|E|\le 1$ 时模型会给出怎样的结论,以及这在现实中意味着什么。这个过程会把本书的建模、微积分与判断力合为一体。
