Fundamental Theorem Calculus Part2

定义。 设 $f$ 在闭区间 $[a, b]$ 上连续，$F$ 是 $f$ 在该区间上的任意一个原函数，即满足 $F'(x) = f(x)$，则定积分由下式给出：

$$\int_a^b f(x)\,dx = F(b) - F(a).$$

此结论通常记作 $\Big[F(x)\Big]_a^b$，即对原函数在上下限处取值之差。微积分基本定理第二部分的核心意义在于：它将求定积分的问题转化为寻找原函数的问题，使得复杂的极限求和过程得以避免。

例题。 计算 $\displaystyle\int_1^3 (2x + 1)\,dx$。

首先求被积函数 $f(x) = 2x + 1$ 的一个原函数。由幂函数积分法则：

$$F(x) = x^2 + x.$$

验证：$F'(x) = 2x + 1 = f(x)$，满足条件。代入上下限：

$$\int_1^3 (2x+1)\,dx = F(3) - F(1) = (9 + 3) - (1 + 1) = 12 - 2 = 10.$$

几何意义上，此结果等于曲线 $y = 2x+1$ 在区间 $[1,3]$ 上方、$x$ 轴上方所围梯形的面积，可直接验证：面积 $= \tfrac{1}{2}(3 + 7)\times 2 = 10$，与积分结果一致。

关键定理（微积分基本定理第二部分）。 若 $f$ 在 $[a,b]$ 上连续，$F$ 为其原函数，则：

$$\int_a^b f(x)\,dx = F(b) - F(a).$$

证明概要。 由微积分基本定理第一部分，定义累积函数 $G(x) = \int_a^x f(t)\,dt$，则 $G'(x) = f(x)$。因此 $G$ 与 $F$ 均为 $f$ 的原函数，故 $F(x) = G(x) + C$（$C$ 为常数）。于是

$$F(b) - F(a) = G(b) - G(a) = \int_a^b f(t)\,dt - 0 = \int_a^b f(x)\,dx. \quad \square$$

实验单元（SymPy）。

from sympy import symbols, integrate, diff

x = symbols('x')
f = 2*x + 1
F = integrate(f, x)          # 求原函数
result = F.subs(x, 3) - F.subs(x, 1)  # 代入上下限
print("原函数 F(x) =", F)
print("定积分值 =", result)
# 验证：diff(F, x) == f
print("验证 F'(x) = f(x):", diff(F, x) == f)

运行上述代码，输出应为 $F(x) = x^2 + x$，积分值为 $10$，验证正确。学生可将被积函数替换为 $\sin x$、$e^x$ 等，观察定理对不同函数的适用性。
