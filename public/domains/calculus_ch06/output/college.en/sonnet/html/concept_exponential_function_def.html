Exponential Function Definition

An exponential function is a function of the form

$$f(x) = a \cdot b^x$$

where $a \neq 0$ is the initial value (the output when $x = 0$), $b > 0$ and $b \neq 1$ is the base, and $x$ is any real number. What makes this function special — and fundamentally different from polynomial functions — is that the variable $x$ sits in the exponent rather than the base. When $b > 1$, the function grows without bound as $x$ increases; when $0 < b < 1$, it decays toward zero. Both behaviors appear constantly in science, finance, and computing.

The natural exponential function $f(x) = e^x$, where $e \approx 2.71828$, is the most important special case. It arises naturally whenever a quantity grows at a rate proportional to its current size — bank interest compounding continuously, radioactive decay, population growth in unlimited environments.

Worked Example

Suppose a bacterial culture starts with 500 cells and doubles every 3 hours. Write an exponential function for the population $P$ after $t$ hours, then find the population after 9 hours.

The doubling time is 3 hours, so the base is $2$ and the exponent must equal $1$ after every 3 hours. This gives:

$$P(t) = 500 \cdot 2^{t/3}$$

At $t = 9$:

$$P(9) = 500 \cdot 2^{9/3} = 500 \cdot 2^3 = 500 \cdot 8 = 4{,}000 \text{ cells}$$

Problem-Solving Application

Exponential functions appear any time a quantity changes by a constant multiplicative factor over equal time intervals — this is the key diagnostic. If you see a table of values where the ratio $f(x+1)/f(x)$ is constant, the relationship is exponential (not linear, where the difference is constant).

To identify the model from data: (1) check whether consecutive ratios are approximately equal; (2) read $a$ as the $y$-intercept; (3) read $b$ as that common ratio. To find when a quantity reaches a target value, set up the equation $a \cdot b^x = \text{target}$ and solve using logarithms:

$$x = \frac{\ln(\text{target}/a)}{\ln b}$$

This logarithm step is the standard tool for "unlocking" an unknown exponent, and it connects exponential functions directly to their inverses.
