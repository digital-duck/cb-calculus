Linear Function

Definition. A linear function is a function $f : \mathbb{R} \to \mathbb{R}$ of the form

$$f(x) = mx + b,$$

where $m, b \in \mathbb{R}$ are constants. The constant $m$ is called the slope (or gradient) and $b$ is the y-intercept. The defining characteristic of a linear function is that equal increments in the input produce equal increments in the output: for any $x_1, x_2 \in \mathbb{R}$,

$$f(x_2) - f(x_1) = m(x_2 - x_1).$$

This property is equivalent to saying that the graph of $f$ is a straight line in the Cartesian plane.

Worked Example. Let $f(x) = 3x - 2$. Find the value of $f$ at $x = 4$, and determine the input $x_0$ such that $f(x_0) = 7$.

Solution. Evaluating directly: $f(4) = 3(4) - 2 = 10$. To solve $f(x_0) = 7$, write

$$3x_0 - 2 = 7 \implies 3x_0 = 9 \implies x_0 = 3.$$

Geometrically, the slope $m = 3$ tells us that for every one-unit increase in $x$, the output rises by $3$. The graph crosses the $y$-axis at $(0, -2)$ and the $x$-axis (the zero of $f$) at $\bigl(\tfrac{2}{3}, 0\bigr)$.

Key Theorem. A function $f : \mathbb{R} \to \mathbb{R}$ is linear (affine) if and only if it satisfies the following two conditions for all $x, y \in \mathbb{R}$ and $\alpha \in \mathbb{R}$:

  • Additivity up to a constant: $f(x + y) = f(x) + f(y) - b$,
  • Homogeneity up to a constant: $f(\alpha x) = \alpha f(x) - (\alpha - 1)b$.

    • When $b = 0$, these reduce to the standard conditions of linearity, $f(x+y) = f(x)+f(y)$ and $f(\alpha x) = \alpha f(x)$, making $f$ a linear map in the strict algebraic sense. The general case $b \neq 0$ is more precisely called an affine function, though "linear function" is the conventional term in introductory analysis.

    Lab Cell.

    from sympy import symbols, solve, plot

x = symbols('x')
f = 3*x - 2

print("f(4) =", f.subs(x, 4))
print("zero of f:", solve(f, x))

plot(f, (x, -2, 5), title='f(x) = 3x - 2',
     xlabel='x', ylabel='f(x)')

    Running this cell confirms $f(4) = 10$, the zero at $x = \tfrac{2}{3}$, and produces a plot of the line with slope $3$ crossing the $y$-axis at $-2$.
