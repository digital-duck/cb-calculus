Linear Function

A linear function is a function of the form $f(x) = mx + b$, where $m$ is the slope and $b$ is the y-intercept. The word linear reflects the geometry: the graph is always a straight line. Two properties define linearity algebraically — additivity ($f(x_1 + x_2) = f(x_1) + f(x_2)$) and homogeneity ($f(cx) = cf(x)$) — but for a general linear function with a nonzero intercept, only the slope relationship needs to hold: equal changes in input produce equal changes in output. That constancy of rate is the core idea.

Worked example. A water tank drains at a steady rate of 15 liters per minute. At $t = 0$ the tank holds 300 liters. Model the volume and find when the tank is empty.

Set up the function: the volume decreases at a constant rate, so

$$V(t) = 300 - 15t$$

Here $m = -15$ (liters per minute) and $b = 300$ (initial volume). To find when the tank empties, set $V(t) = 0$:

$$300 - 15t = 0 \implies t = \frac{300}{15} = 20 \text{ minutes}$$

The tank is empty after 20 minutes. Notice the slope carried a physical unit — liters per minute — which is almost always more meaningful than the abstract number alone.

Problem-solving application. Linear functions are the go-to model whenever a quantity changes at a constant rate, because that single rate determines everything else. Given any two points $(x_1, y_1)$ and $(x_2, y_2)$ on the line, you can recover the slope:

$$m = \frac{y_2 - y_1}{x_2 - x_1}$$

then substitute one point into $y = mx + b$ to solve for $b$. From that fully determined function you can extrapolate (predict values outside the data range) or interpolate (estimate values between known points).

A caution: extrapolation assumes the rate stays constant, which physical and social systems rarely guarantee indefinitely. The draining tank empties at $t = 20$; the function $V(t)$ produces negative values for $t > 20$, which is mathematically valid but physically meaningless. Always check whether the domain makes sense for the context, and treat predictions far outside your observed range as estimates, not facts. Linear functions are powerful precisely because they are simple — but that simplicity is an assumption you have to earn, not a default.
