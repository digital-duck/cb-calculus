Quadratic Function

Definition. A quadratic function is any function $f : \mathbb{R} \to \mathbb{R}$ of the form

$$f(x) = ax^2 + bx + c, \qquad a, b, c \in \mathbb{R},\; a \neq 0.$$

The condition $a \neq 0$ distinguishes it from a linear function. The graph of $f$ is a parabola with vertical axis of symmetry $x = -b/(2a)$ and vertex at

$$V = \left(-\frac{b}{2a},\; f\!\left(-\frac{b}{2a}\right)\right).$$

When $a > 0$ the parabola opens upward and $V$ is a global minimum; when $a < 0$ it opens downward and $V$ is a global maximum.

Worked Example. Let $f(x) = 2x^2 - 8x + 6$.

  • Axis of symmetry. $x = -(-8)/(2 \cdot 2) = 2$.
  • Vertex. $f(2) = 2(4) - 16 + 6 = -2$, so $V = (2, -2)$.
  • Roots. Setting $f(x) = 0$ and applying the quadratic formula:
    • $$x = \frac{8 \pm \sqrt{64 - 48}}{4} = \frac{8 \pm 4}{4}.$$

    Hence $x = 3$ and $x = 1$. The parabola crosses the $x$-axis at $(1, 0)$ and $(3, 0)$, symmetric about $x = 2$. $\checkmark$

    Theorem (Quadratic Formula). If $a \neq 0$, the solutions to $ax^2 + bx + c = 0$ are

    $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}.$$

    The quantity $\Delta = b^2 - 4ac$ is called the discriminant. The equation has two distinct real roots if $\Delta > 0$, one repeated real root if $\Delta = 0$, and no real roots (two complex conjugate roots) if $\Delta < 0$.

    Proof sketch. Complete the square: $a(x + b/2a)^2 = (b^2 - 4ac)/4a$. Taking the square root of both sides and solving for $x$ yields the formula. $\square$

    Lab Cell.

    from sympy import symbols, solve, factor, latex

x = symbols('x')
f = 2*x**2 - 8*x + 6

roots   = solve(f, x)          # [1, 3]
factored = factor(f)           # 2*(x - 1)*(x - 3)
print(roots, latex(factored))

    Running this cell confirms the roots $x = 1, 3$ and displays the factored form $2(x-1)(x-3)$, illustrating how symbolic computation validates hand calculation.
