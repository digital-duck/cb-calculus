Relation

A relation from a set $A$ to a set $B$ is any subset $R \subseteq A \times B$, where $A \times B$ is the Cartesian product — the set of all ordered pairs $(a, b)$ with $a \in A$ and $b \in B$. Writing $a \mathrel{R} b$ means the pair $(a, b)$ belongs to $R$. When $A = B$, we call $R$ a relation on $A$.

This definition is more general than it first appears. "Is less than" on $\mathbb{Z}$ is a relation: $3 \mathrel{<} 7$ simply means $(3, 7) \in \{(a,b) \mid a < b\}$. "Is a sibling of" on a set of people is a relation. Even a function $f : A \to B$ is a special relation — specifically, one where every $a \in A$ appears in exactly one pair. Relations are the broader category; functions are the well-behaved special case.

Worked example. Let $A = \{1, 2, 3\}$ and define $R = \{(1,1),(2,2),(3,3),(1,2),(2,1)\}$. Is $(1,3) \in R$? No — check the list. Is $(2,1) \in R$? Yes. Notice that $R$ satisfies three useful properties: every element is related to itself (reflexive), whenever $a \mathrel{R} b$ then $b \mathrel{R} a$ (symmetric), and whenever $a \mathrel{R} b$ and $b \mathrel{R} c$ then $a \mathrel{R} c$ (transitive — you can verify this holds here). A relation with all three properties is called an equivalence relation, and it partitions $A$ into disjoint clusters called equivalence classes.

Problem-solving application. Suppose you must decide whether "has the same remainder when divided by 3" is an equivalence relation on $\mathbb{Z}$. Work through each property:

  • Reflexive: $a - a = 0$, which is divisible by 3, so $a \mathrel{R} a$. ✓
  • Symmetric: if $3 \mid (a - b)$, then $3 \mid (b - a)$. ✓
  • Transitive: if $3 \mid (a - b)$ and $3 \mid (b - c)$, then $3 \mid (a - c)$ because $(a - c) = (a - b) + (b - c)$. ✓

    • All three hold, so $R$ is an equivalence relation, and it partitions $\mathbb{Z}$ into exactly three equivalence classes: $\{..., -3, 0, 3, 6, ...\}$, $\{..., -2, 1, 4, 7, ...\}$, and $\{..., -1, 2, 5, 8, ...\}$. This structure — modular arithmetic — is the foundation of cryptography, hash tables, and error-correcting codes.
