Mathematical Model

Definition. A mathematical model is a formal representation of a real-world system using mathematical language — equations, functions, inequalities, or stochastic processes — that captures the essential structure of the system while deliberately abstracting away irrelevant detail. Formally, a model consists of a tuple $\mathcal{M} = (S, \mathcal{P}, f, \Omega)$, where $S$ is the state space, $\mathcal{P}$ is a set of parameters, $f: S \times \mathcal{P} \to S$ is the governing law (a differential equation, recurrence, or map), and $\Omega$ encodes boundary or initial conditions. The model is called deterministic when $f$ is a single-valued function and stochastic when $f$ is replaced by a probability kernel.

Worked Example. Consider a population of bacteria growing in a nutrient-rich flask. Let $N(t)$ denote the population size at time $t \geq 0$. Observing that each individual reproduces at a constant per-capita rate $r > 0$, we write the governing law as

$$\frac{dN}{dt} = r N, \qquad N(0) = N_0.$$

Here $S = \mathbb{R}_{\geq 0}$, $\mathcal{P} = \{r\}$, and the initial condition $\Omega = \{N(0) = N_0\}$. Separating variables and integrating yields the closed-form solution

$$N(t) = N_0 e^{rt}.$$

For $r = 0.3\ \text{h}^{-1}$ and $N_0 = 100$, the model predicts $N(2) = 100\,e^{0.6} \approx 182$ cells after two hours. This is the exponential growth model, the simplest non-trivial continuous deterministic model in biology.

Key Theorem (Well-Posedness, Picard–Lindelöf). Let $f(t, x)$ be continuous on an open set $U \subseteq \mathbb{R} \times \mathbb{R}^n$ and Lipschitz continuous in $x$. Then for any $(t_0, x_0) \in U$ there exists a unique solution $x(t)$ to $\dot{x} = f(t, x)$, $x(t_0) = x_0$, on some interval containing $t_0$. Well-posedness — existence, uniqueness, and continuous dependence on initial data — is the minimum standard a mathematical model must satisfy to be scientifically meaningful.

Lab Cell.

import sympy as sp

t, r, N0 = sp.symbols('t r N_0', positive=True)
N = sp.Function('N')

ode = sp.Eq(N(t).diff(t), r * N(t))
solution = sp.dsolve(ode, N(t), ics={N(0): N0})
print(solution)                        # N(t) = N0 * exp(r*t)

# Evaluate at r=0.3, N0=100, t=2
numerical = solution.rhs.subs({r: 0.3, N0: 100, t: 2})
print(float(numerical))                # ≈ 182.2
