Area Problem

Definition. The area problem asks: given a continuous function $f : [a, b] \to \mathbb{R}$ with $f(x) \geq 0$, what is the exact area of the region bounded above by the graph of $f$, below by the $x$-axis, and laterally by the vertical lines $x = a$ and $x = b$? For straight-edged regions this question is elementary, but when $f$ is nonlinear, no finite collection of rectangles or triangles covers the region without error. The area problem is the geometric motivation for the definite integral $\displaystyle\int_a^b f(x)\,dx$.

Worked Example. Estimate the area under $f(x) = x^2$ on $[0, 1]$ using $n = 4$ equal subintervals of width $\Delta x = \tfrac{1}{4}$, taking right endpoints $x_k = k/4$ for $k = 1, 2, 3, 4$.

$$R_4 = \sum_{k=1}^{4} f\!\left(\tfrac{k}{4}\right)\Delta x = \frac{1}{4}\left[\left(\tfrac{1}{4}\right)^2 + \left(\tfrac{2}{4}\right)^2 + \left(\tfrac{3}{4}\right)^2 + \left(\tfrac{4}{4}\right)^2\right] = \frac{1}{4}\cdot\frac{1+4+9+16}{16} = \frac{30}{64} = \frac{15}{32} \approx 0.469.$$

The true area is $1/3 \approx 0.333$, so $R_4$ overestimates by roughly $41\%$. As $n \to \infty$ the error vanishes, because the maximum subinterval width $\|\Delta x\| \to 0$ and the oscillation of $f$ on each piece becomes negligible.

Key Theorem (Existence of the Definite Integral). If $f$ is continuous on $[a, b]$, then for any sequence of Riemann sums

$$S_n = \sum_{k=1}^{n} f(x_k^*)\,\Delta x_k, \qquad x_k^* \in [x_{k-1}, x_k],$$

the limit $\lim_{n \to \infty} S_n$ exists, is finite, and is independent of the choice of sample points $x_k^*$. This common limit is defined to be $\displaystyle\int_a^b f(x)\,dx$.

Proof sketch. Continuity on a closed interval implies uniform continuity, so the oscillation $\omega_k = \max f - \min f$ on each subinterval satisfies $\omega_k \leq \epsilon$ for all $k$ once $\|\Delta x\|$ is small enough. The difference between any two Riemann sums is then bounded by $\epsilon(b-a)$, which can be made arbitrarily small, establishing convergence by the Cauchy criterion.

Lab Cell.

from sympy import symbols, integrate, Rational, summation, oo

x, k, n = symbols('x k n', positive=True)

# Exact area via definite integral
exact = integrate(x**2, (x, 0, 1))
print("Exact area:", exact)          # 1/3

# Right-endpoint Riemann sum for general n
dx   = Rational(1) / n
xk   = k * dx
Rn   = summation(xk**2 * dx, (k, 1, n))
print("R_n =", Rn.simplify())        # (2n^2 + 3n + 1)/(6n^2)
print("Limit:", Rn.limit(n, oo))     # 1/3
