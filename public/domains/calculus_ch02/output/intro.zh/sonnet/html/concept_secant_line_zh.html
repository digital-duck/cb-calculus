Secant Line

定义。 设函数 $f$ 在包含点 $a$ 与 $b$（$a \neq b$）的区间上有定义。过曲线 $y = f(x)$ 上两点 $P = (a,\, f(a))$ 与 $Q = (b,\, f(b))$ 的直线称为 $f$ 在该区间上的割线（secant line）。其斜率由差商给出：

$$m_{\sec} = \frac{f(b) - f(a)}{b - a}.$$

若令 $h = b - a$，则可将差商改写为

$$m_{\sec} = \frac{f(a + h) - f(a)}{h}, \quad h \neq 0.$$

割线的几何意义在于：它以有限步长逼近曲线的局部走势，是微分学中切线概念的基础前驱。

例题。 设 $f(x) = x^2$，取 $a = 1$，$b = 3$。

计算割线斜率：

$$m_{\sec} = \frac{f(3) - f(1)}{3 - 1} = \frac{9 - 1}{2} = 4.$$

过点 $P = (1, 1)$，割线方程为：

$$y - 1 = 4(x - 1) \implies y = 4x - 3.$$

可验证：当 $x = 3$ 时，$y = 4(3) - 3 = 9 = f(3)$，割线确实经过点 $Q = (3, 9)$。

关键定理（割线极限与导数）。 若 $f$ 在点 $a$ 处可微，则当 $b \to a$（即 $h \to 0$）时，割线斜率趋近于切线斜率：

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}.$$

证明思路： 差商 $\dfrac{f(a+h)-f(a)}{h}$ 对每个固定的 $h \neq 0$ 均有意义，且随 $h \to 0$ 给出一个极限（若该极限存在），此极限即为导数的定义。割线在几何上"旋转"逼近切线，斜率序列收敛正是可微性的精确表述。

实验单元（SymPy）。

from sympy import symbols, simplify

x, a, h = symbols('x a h')
f = x**2

# 计算差商
secant_slope = simplify((f.subs(x, a + h) - f.subs(x, a)) / h)
print("割线斜率：", secant_slope)   # 输出：2*a + h

# 令 h → 0，得到导数
from sympy import limit
derivative = limit(secant_slope, h, 0)
print("导数 f'(a)：", derivative)   # 输出：2*a

运行上述代码，可直观验证：差商 $2a + h$ 在 $h \to 0$ 时确实趋近于 $f'(a) = 2a$，印证了割线向切线过渡的过程。
