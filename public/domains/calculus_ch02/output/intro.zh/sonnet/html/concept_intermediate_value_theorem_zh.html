Intermediate Value Theorem

定义

设函数 $f$ 在闭区间 $[a, b]$ 上连续，且 $f(a) \neq f(b)$。若 $k$ 是介于 $f(a)$ 与 $f(b)$ 之间的任意实数，即

$$\min\{f(a),\, f(b)\} < k < \max\{f(a),\, f(b)\},$$

则至少存在一点 $c \in (a, b)$，使得 $f(c) = k$。

这一定理的本质在于：连续函数的图像不能"跳跃"——从一个值出发，到达另一个值，必然经过中间的每一个值。正如一个人从海拔 $0$ 米攀登至海拔 $3000$ 米，必然在某一时刻身处海拔 $1500$ 米处。

具体例子

考察函数 $f(x) = x^3 - x - 1$，试证明方程 $f(x) = 0$ 在区间 $[1, 2]$ 上有实根。

计算端点处的函数值：

$$f(1) = 1 - 1 - 1 = -1 < 0,$$ $$f(2) = 8 - 2 - 1 = 5 > 0.$$

由于 $f(1) < 0 < f(2)$，而 $f$ 在 $[1, 2]$ 上连续（多项式函数处处连续），由介值定理知，存在 $c \in (1, 2)$ 使得 $f(c) = 0$，即方程在该区间内至少有一个实根。

关键定理

介值定理（正式陈述）：若 $f \in C[a, b]$（即 $f$ 在 $[a, b]$ 上连续），则 $f$ 在 $[a, b]$ 上的值域包含区间 $[\min\{f(a), f(b)\},\, \max\{f(a), f(b)\}]$。

证明思路：令 $S = \{x \in [a,b] : f(x) < k\}$。由 $f(a) < k$ 知 $S$ 非空且有上界 $b$，故上确界 $c = \sup S$ 存在。利用 $f$ 的连续性及上确界的定义，可导出 $f(c) = k$，矛盾假设 $f(c) \neq k$ 将产生逻辑矛盾，故结论成立。

实验单元（SymPy）

import sympy as sp

x = sp.Symbol('x')
f = x**3 - x - 1

# 在 [1, 2] 上寻找零点
root = sp.solve(f, x)
numerical_roots = [r.evalf() for r in root if r.is_real]

print("精确根：", root)
print("数值近似：", numerical_roots)

# 验证介值条件
print(f"f(1) = {f.subs(x, 1)},  f(2) = {f.subs(x, 2)}")

运行上述代码可验证：方程 $x^3 - x - 1 = 0$ 在 $(1, 2)$ 内确有唯一实根，约为 $x \approx 1.3247$，与介值定理的存在性预测完全吻合。
