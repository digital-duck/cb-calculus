微分学的本质成就

微分学是分析学的核心引擎。给定函数 $f: \mathbb{R} \to \mathbb{R}$，其在点 $x_0$ 处的导数定义为极限

$$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h},$$

若此极限存在，则称 $f$ 在 $x_0$ 处可微。导数捕捉了函数在无穷小尺度下的线性近似——切线斜率——从而将整体非线性行为化归为局部线性结构。这一化归正是微分学成为数学与科学核心工具的根本原因。

典型例证

考察 $f(x) = x^3 - 3x$。由导数定义（或幂法则）得 $f'(x) = 3x^2 - 3$。令 $f'(x) = 0$，解出 $x = \pm 1$。再由二阶导数 $f''(x) = 6x$ 判断：$f''(1) = 6 > 0$，故 $x = 1$ 为局部极小值；$f''(-1) = -6 < 0$，故 $x = -1$ 为局部极大值。仅凭导数运算，我们便完整刻画了函数的单调性与极值结构。

核心定理

中值定理　设 $f$ 在闭区间 $[a,b]$ 上连续，在开区间 $(a,b)$ 上可微，则存在 $c \in (a,b)$ 使得

$$f'(c) = \frac{f(b) - f(a)}{b - a}.$$

此定理是泰勒展开、洛必达法则与数值积分误差估计的共同基础，是贯穿全书的结构性命题。

实验单元（SymPy）

from sympy import symbols, diff, solve, simplify

x = symbols('x')
f = x**3 - 3*x
fp  = diff(f, x)          # 一阶导数
fpp = diff(f, x, 2)       # 二阶导数
crits = solve(fp, x)      # 临界点
classification = {c: simplify(fpp.subs(x, c)) for c in crits}
print(classification)     # {-1: -6, 1: 6}

微分学并非终点，而是一扇门。它将静态函数转化为动态信息：速度、曲率、灵敏度、最优性条件。从物理学中的牛顿运动方程，到机器学习中的梯度下降，再到经济学中的边际分析，每一个现代定量学科都建立在导数这一概念之上。建议读者选择其中一个最令自己着迷的应用领域，带着本书所建立的微分工具，深入探索——你将发现，同一套语言可以精确描述截然不同的世界。
