积分学的成就

积分学是微积分体系的自然终点，它将"无限求和"这一直觉赋予严格的数学形式。给定定义在闭区间 $[a, b]$ 上的连续函数 $f$，其定积分

$$\int_a^b f(x)\,dx = \lim_{n\to\infty} \sum_{k=1}^n f(x_k^*)\,\Delta x$$

将无穷多个无穷小量精确地汇聚为一个有限数值。若说微分学教会我们"在一点处如何变化"，那么积分学则回答了"在一段历程中积累了多少"。这两个问题由微积分基本定理（FTC）紧密相连：

$$\int_a^b f(x)\,dx = F(b) - F(a), \quad F'(x) = f(x).$$

具体例题

设 $f(x) = 3x^2$，计算 $\int_0^2 3x^2\,dx$。

取原函数 $F(x) = x^3$，由 FTC 得

$$\int_0^2 3x^2\,dx = F(2) - F(0) = 8 - 0 = 8.$$

几何上，这正是曲线 $y = 3x^2$ 与 $x$ 轴之间、$x \in [0,2]$ 范围内的面积。

核心定理

定理（微积分基本定理）：若 $f$ 在 $[a,b]$ 上连续，令 $F(x) = \int_a^x f(t)\,dt$，则 $F$ 在 $(a,b)$ 上可微且 $F'(x) = f(x)$。

此定理揭示了微分与积分的互逆性，使计算从繁琐的黎曼和转化为寻找原函数的代数操作。

通向多元微积分

掌握单变量积分后，多元微积分的大门随之开启。二重积分 $\iint_D f(x,y)\,dA$ 将"沿一条轴的求和"推广为"沿一片区域的求和"，可用于计算曲面下的体积、质心与转动惯量。三重积分与曲线积分进一步涵盖三维空间中的通量与环流，最终由高斯散度定理和斯托克斯定理将体积分与面积分、面积分与线积分统一连接，构成向量分析的宏大图景。

# 实验室：用 SymPy 验证上述例题并探索符号积分
from sympy import symbols, integrate, diff

x = symbols('x')
f = 3*x**2
F = integrate(f, x)          # 求原函数
result = F.subs(x, 2) - F.subs(x, 0)
print("原函数 F(x) =", F)
print("定积分值 =", result)   # 输出：8

现在，请深入探索多元微积分：当一个函数同时依赖两个或更多变量时，积分如何在高维曲面上展开？从二重积分的换序法则出发，您将领略积分学在物理、工程与数据科学中最壮阔的应用舞台。
