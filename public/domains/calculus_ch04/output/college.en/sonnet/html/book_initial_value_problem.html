Concept Book: Initial Value Problem

Calculus Ch04 · Generated by SPL

Payoff

An initial value problem (IVP) couples an ordinary differential equation with a prescribed state at a single instant, giving the system enough information to determine a unique future trajectory. Formally, given a function $f : \mathbb{R} \times \mathbb{R}^n \to \mathbb{R}^n$, an IVP asks for a differentiable curve $\mathbf{y} : [t_0, T] \to \mathbb{R}^n$ satisfying

$$\frac{d\mathbf{y}}{dt} = f(t, \mathbf{y}), \qquad \mathbf{y}(t_0) = \mathbf{y}_0.$$

The Picard–Lindelöf theorem guarantees that when $f$ is Lipschitz continuous in $\mathbf{y}$, exactly one such curve exists on some interval containing $t_0$. This theorem is the conceptual capstone of the course: every technique studied — separation of variables, integrating factors, eigenvalue decomposition, numerical stepping — is ultimately a strategy for constructing or approximating that unique solution.

Worked example. A mass $m = 1\,\text{kg}$ hangs from a spring with constant $k = 4\,\text{N/m}$ and is released from rest at displacement $y_0 = 0.5\,\text{m}$. The IVP is

$$\ddot{y} + 4y = 0, \qquad y(0) = 0.5,\quad \dot{y}(0) = 0.$$

The characteristic roots are $\pm 2i$, giving the general solution $y(t) = A\cos 2t + B\sin 2t$. Applying the initial conditions yields $A = 0.5$ and $B = 0$, so $y(t) = 0.5\cos 2t$. The initial condition selects the single physical oscillation from an infinite family of mathematical possibilities.

Key theorem (Picard–Lindelöf). If $f(t, \mathbf{y})$ is continuous on a rectangle $R = [t_0 - a, t_0 + a] \times B(\mathbf{y}_0, b)$ and satisfies $\|f(t,\mathbf{u}) - f(t,\mathbf{v})\| \le L\|\mathbf{u}-\mathbf{v}\|$ for all $(t,\mathbf{u}),(t,\mathbf{v})\in R$, then there exists $h > 0$ and a unique solution to the IVP on $[t_0 - h, t_0 + h]$.

Lab cell.

from sympy import *
t = symbols('t')
y = Function('y')
ode = Eq(y(t).diff(t, 2) + 4*y(t), 0)
sol = dsolve(ode, y(t), ics={y(0): Rational(1,2), y(t).diff(t).subs(t,0): 0})
print(sol)

The IVP is the natural endpoint of this text because it transforms differential equations from descriptive tools into predictive engines. A differential equation without an initial condition describes every possible behavior of a family of systems; the initial condition pins the model to one physical reality. This unifying principle recurs across all quantitative science: in population ecology, the initial population size determines which logistic curve a species follows; in circuit analysis, initial charges and currents determine the transient response; in orbital mechanics, a spacecraft's position and velocity at engine cut-off determine its entire subsequent trajectory.

Choose one of these domains and carry the IVP forward — you now possess every mathematical tool required to build, solve, and interpret the model from first principles.
