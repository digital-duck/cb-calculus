Mean Value Theorem

定义。 设函数 $f$ 在闭区间 $[a, b]$ 上连续，在开区间 $(a, b)$ 上可微。则存在至少一点 $c \in (a, b)$，使得

$$f'(c) = \frac{f(b) - f(a)}{b - a}.$$

这一结论称为微分中值定理（Mean Value Theorem，简称 MVT）。其几何含义是：在满足上述条件的曲线上，至少存在一点处的切线与连接端点 $(a, f(a))$ 和 $(b, f(b))$ 的割线平行。

证明思路。 构造辅助函数

$$g(x) = f(x) - f(a) - \frac{f(b)-f(a)}{b-a}(x - a).$$

可以验证 $g(a) = g(b) = 0$。由于 $f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 上可微，$g$ 亦满足相同条件，故由罗尔定理（Rolle's Theorem）知，存在 $c \in (a,b)$ 使得 $g'(c) = 0$，即

$$f'(c) - \frac{f(b)-f(a)}{b-a} = 0,$$

由此得出定理结论。$\blacksquare$

工作例题。 设 $f(x) = x^3 - 3x$，区间为 $[0, 2]$。

首先计算割线斜率：

$$\frac{f(2) - f(0)}{2 - 0} = \frac{(8 - 6) - 0}{2} = \frac{2}{2} = 1.$$

令 $f'(x) = 3x^2 - 3 = 1$，解得 $3x^2 = 4$，即

$$x = \frac{2}{\sqrt{3}} = \frac{2\sqrt{3}}{3} \approx 1.155.$$

由于 $\frac{2\sqrt{3}}{3} \in (0,2)$，中值定理得以验证，此点处切线斜率恰好等于 $1$。

关键推论。 若 $f'(x) = 0$ 在区间 $(a,b)$ 上处处成立，则 $f$ 在该区间上为常数函数。这一推论是不定积分唯一性（相差常数）的理论基础。

实验单元（SymPy）。

from sympy import *
x, c = symbols('x c', real=True)
f = x**3 - 3*x
a_val, b_val = 0, 2
slope = (f.subs(x, b_val) - f.subs(x, a_val)) / (b_val - a_val)
c_vals = solve(diff(f, x) - slope, x)
print("割线斜率:", slope)          # 输出: 1
print("中值点 c:", c_vals)         # 输出: [-2√3/3, 2√3/3]

运行上述代码，取满足 $c \in (0,2)$ 的正根，即可在数值上确认定理结论。
