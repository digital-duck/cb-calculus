Absolute Extrema

定义。 设函数 $f$ 定义在区间 $I$ 上。若存在点 $c \in I$，使得对所有 $x \in I$ 均有 $f(c) \geq f(x)$，则称 $f(c)$ 为 $f$ 在 $I$ 上的绝对最大值（全局最大值）；若对所有 $x \in I$ 均有 $f(c) \leq f(x)$，则称 $f(c)$ 为 $f$ 在 $I$ 上的绝对最小值（全局最小值）。绝对最大值与绝对最小值统称为绝对极值（绝对极端值）。

极值存在定理（闭区间定理）。 若函数 $f$ 在闭区间 $[a, b]$ 上连续，则 $f$ 在 $[a, b]$ 上必同时取得绝对最大值与绝对最小值。该定理的两个条件——连续性与闭区间——缺一不可：开区间 $(0,1)$ 上的函数 $f(x)=x$ 连续却无绝对最大值；闭区间 $[0,1]$ 上的分段函数若含跳跃间断点，同样可能失去极值。

求法（候选点法）。 绝对极值只能在以下三类点上取得：（1）区间端点 $a$、$b$；（2）区间内部满足 $f'(c)=0$ 的驻点；（3）区间内部 $f'$ 不存在的奇异点。依次计算这些候选点处的函数值，最大者为绝对最大值，最小者为绝对最小值。

例题。 求 $f(x) = x^3 - 3x^2 + 1$ 在 $[-\tfrac{1}{2},\, 3]$ 上的绝对极值。

解： 首先求导：$f'(x) = 3x^2 - 6x = 3x(x-2)$。令 $f'(x)=0$，得驻点 $x=0$ 与 $x=2$，均在区间内。列表计算各候选点处的函数值：

| 候选点 | $f$ 值 | |--------|--------| | $x = -\tfrac{1}{2}$ | $(-\tfrac{1}{2})^3 - 3(\tfrac{1}{4}) + 1 = \tfrac{1}{8}$ | | $x = 0$ | $1$ | | $x = 2$ | $8 - 12 + 1 = -3$ | | $x = 3$ | $27 - 27 + 1 = 1$ |

比较可知，绝对最大值为 $\boxed{1}$（在 $x=0$ 与 $x=3$ 处同时取得），绝对最小值为 $\boxed{-3}$（在 $x=2$ 处取得）。

实验单元（SymPy）。

from sympy import *
x = symbols('x')
f = x**3 - 3*x**2 + 1
interval = Rational(-1,2), 3

crit = solve(diff(f, x), x)
candidates = list(interval) + [c for c in crit if interval[0] < c < interval[1]]
vals = {c: f.subs(x, c) for c in candidates}
print("绝对最大值:", max(vals, key=vals.get), "→", max(vals.values()))
print("绝对最小值:", min(vals, key=vals.get), "→", min(vals.values()))
