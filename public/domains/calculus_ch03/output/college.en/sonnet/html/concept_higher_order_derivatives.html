Higher Order Derivatives

When you differentiate a function $f(x)$, you get the derivative $f'(x)$, which measures how fast $f$ is changing. But $f'(x)$ is itself a function — so you can differentiate it again. The result is the second derivative, written $f''(x)$ or $\frac{d^2f}{dx^2}$. Differentiating once more gives the third derivative $f'''(x)$, and so on. These are called higher order derivatives. The $n$-th derivative is denoted $f^{(n)}(x)$.

Each successive derivative tells you something new about the original function's behavior. The first derivative gives slope (rate of change). The second derivative tells you whether that slope is increasing or decreasing — in other words, whether the curve bends upward or downward. A positive second derivative means the graph is concave up (like a bowl); a negative second derivative means concave down (like an arch).

Worked example. Let $f(x) = x^4 - 6x^2 + 1$.

$$f'(x) = 4x^3 - 12x$$ $$f''(x) = 12x^2 - 12$$ $$f'''(x) = 24x$$

At $x = 0$: $f''(0) = -12 < 0$, so the graph is concave down there. At $x = 2$: $f''(2) = 48 - 12 = 36 > 0$, so concave up. The sign of $f''$ switches somewhere between — that switch point, where $f''(x) = 0$, is called an inflection point. Setting $12x^2 - 12 = 0$ gives $x = \pm 1$.

Problem-solving application. Second derivatives are essential for classifying critical points. Suppose $f'(c) = 0$ — you've found a critical point, but is it a local min, max, or neither? The Second Derivative Test resolves this:

  • If $f''(c) > 0$: local minimum (curve bends up, so the function bottoms out there).
  • If $f''(c) < 0$: local maximum (curve bends down, so the function peaks there).
  • If $f''(c) = 0$: test is inconclusive — check $f'''$ or examine the sign of $f'$ on either side.

    • In physics, if $x(t)$ is position, then $x'(t)$ is velocity and $x''(t)$ is acceleration — Newton's second law $F = ma$ is literally a statement about the second derivative of position. Higher order derivatives appear naturally whenever you need to describe not just change, but the change in change.
