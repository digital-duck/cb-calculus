What Marginal Functions Achieve

Throughout this text we have built a precise language for change: limits formalize the intuition of "getting close," derivatives capture instantaneous rates, and rules of differentiation turn symbolic manipulation into a systematic craft. The concept of marginal functions is the natural endpoint of this progression because it translates all of that machinery into a single, decision-relevant object: the cost, revenue, or value produced by the next unit.

Formally, if $F(q)$ denotes the total value of a quantity $q$, the marginal function is defined as

$$M(q) = F'(q) = \lim_{\Delta q \to 0} \frac{F(q + \Delta q) - F(q)}{\Delta q}.$$

The adjective marginal signals that we care not about the accumulated total but about the local rate of accumulation — precisely what a derivative measures.

Worked Example

Let total cost be $C(q) = 0.01q^3 - 0.6q^2 + 14q + 100$ (dollars, $q$ units). The marginal cost is

$$MC(q) = C'(q) = 0.03q^2 - 1.2q + 14.$$

At $q = 20$, $MC(20) = 0.03(400) - 1.2(20) + 14 = 12 - 24 + 14 = 2$ dollars per unit. Producing the twenty-first unit costs approximately \$2 — far below the average cost $C(20)/20 = \$7$, signaling that expansion is still efficient.

Key Theorem

Optimality condition. If $\pi(q) = R(q) - C(q)$ is a differentiable profit function, then any interior maximum satisfies $MR(q^) = MC(q^)$, i.e., marginal revenue equals marginal cost. This follows immediately from Fermat's theorem: $\pi'(q^) = R'(q^) - C'(q^*) = 0$.

Lab Cell (SymPy)

from sympy import symbols, diff, solve, Rational

q = symbols('q', positive=True)
C = Rational(1,100)*q**3 - Rational(3,5)*q**2 + 14*q + 100
R = 20*q

MC = diff(C, q)
MR = diff(R, q)
q_star = solve(MR - MC, q)
print(f"Optimal quantity: {q_star}")
print(f"Marginal cost at optimum: {MC.subs(q, q_star[0])}")

The marginal framework you have now mastered is the entry point to every quantitative field that must allocate scarce resources. Choose one domain and carry this single equation — $MR = MC$ — into it; you will find it already waiting there, often in disguise.
