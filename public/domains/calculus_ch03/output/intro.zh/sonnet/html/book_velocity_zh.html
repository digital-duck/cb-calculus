速度的本质与意义

纵观本书的概念阶梯——从极限、连续性、导数，到函数的局部线性近似——每一步都在为同一个问题积蓄力量：运动如何被精确描述？ 速度（velocity）正是这一追问的自然终点。它不仅是位移关于时间的导数，更是微积分语言与物理世界之间最直接的翻译。

设质点的位置函数为 $x(t)$，则其瞬时速度定义为

$$v(t) = \lim_{\Delta t \to 0} \frac{x(t + \Delta t) - x(t)}{\Delta t} = \frac{\mathrm{d}x}{\mathrm{d}t}.$$

这一定义将"快慢"从直觉升华为精确量：速度携带方向（正负号）与大小，完整编码了质点在某一瞬间的运动状态。

具体示例

设 $x(t) = 3t^2 - 4t + 1$（单位：米，时间单位：秒）。对其求导得

$$v(t) = 6t - 4.$$

在 $t = 2\,\mathrm{s}$ 时，$v(2) = 8\,\mathrm{m/s}$，表明质点此刻以 $8\,\mathrm{m/s}$ 的速率向正方向运动。当 $v(t) = 0$，即 $t = \tfrac{2}{3}\,\mathrm{s}$ 时，质点瞬间静止——这正是位置函数取极值的时刻，体现了导数零点与极值的深刻联系。

核心定理

微积分基本定理（运动形式）：若 $v(t)$ 在 $[a,b]$ 上连续，则质点在该时间段内的位移为

$$\Delta x = \int_a^b v(t)\,\mathrm{d}t.$$

速度因此成为连接微分与积分两大运算的枢纽：对位置求导得速度，对速度积分复原位移，形成完美的逆运算对称。

SymPy 实验单元

import sympy as sp
t = sp.Symbol('t')
x = 3*t**2 - 4*t + 1
v = sp.diff(x, t)
print("速度函数:", v)
print("t=2 时的速度:", v.subs(t, 2))
print("位移 (0→3 s):", sp.integrate(v, (t, 0, 3)))

通往加速度的邀请

速度描述运动的当下，而加速度则追问速度本身如何变化——它是速度的导数，$a(t) = \dfrac{\mathrm{d}v}{\mathrm{d}t}$，也是牛顿第二定律 $F = ma$ 的核心变量。掌握了速度，你已站在动力学的门槛之上。不妨继续探索：是什么力量改变了速度？ 加速度将给出答案。
