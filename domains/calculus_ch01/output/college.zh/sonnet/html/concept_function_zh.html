函数

定义。 函数是一种规则，它将一个集合（定义域）中的每个元素恰好映射到另一个集合（值域）中的一个元素。用符号表示：若 $f: A \to B$，则对 $A$ 中的每个 $x$，都存在唯一的 $y = f(x) \in B$ 与之对应。"唯一"是关键——同一个输入不能产生两个不同的输出，否则就不是函数。

函数并不局限于数字。它可以将单词映射到其长度，将学生 ID 映射到成绩，或将图像映射到分类标签。理解函数的本质是理解"输入→规则→输出"这一结构。

具体示例。 考虑函数 $f(x) = x^2 - 3x + 2$，定义域为实数集 $\mathbb{R}$。

求 $f(5)$：

$$f(5) = 5^2 - 3 \cdot 5 + 2 = 25 - 15 + 2 = 12$$

判断 $x = 1$ 和 $x = 2$ 是否为零点（即 $f(x) = 0$ 的解）：

$$f(1) = 1 - 3 + 2 = 0 \quad \checkmark$$ $$f(2) = 4 - 6 + 2 = 0 \quad \checkmark$$

因此，$f(x)$ 可以分解为 $f(x) = (x-1)(x-2)$。这说明函数的代数结构与其零点直接相关。

问题求解应用。 函数思维在编程中无处不在。以下 Python 函数实现了上述多项式，并自动找出其零点附近的值：

def f(x):
    return x**2 - 3*x + 2

# 在区间 [0, 3] 上扫描，找出函数值接近零的点
candidates = [x / 10 for x in range(0, 31)]
zeros = [x for x in candidates if abs(f(x)) < 0.01]
print(zeros)  # 输出：[1.0, 2.0]

这里，f 在代码中的角色与数学中完全一致：给定输入，返回唯一输出。函数的可组合性同样重要——可以将 f 作为参数传递给另一个函数，例如绘图工具或数值求解器，而无需修改其内部逻辑。

掌握函数的核心在于区分定义（规则本身）与求值（将规则应用于具体输入）。遇到任何映射关系时，先问：每个输入是否对应唯一输出？若是，即为函数。
