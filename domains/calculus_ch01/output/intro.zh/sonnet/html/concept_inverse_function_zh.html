反函数

定义。 设 $f: A \to B$ 为一个函数。若存在函数 $g: B \to A$，使得对所有 $x \in A$ 有 $g(f(x)) = x$，且对所有 $y \in B$ 有 $f(g(y)) = y$，则称 $g$ 为 $f$ 的反函数，记作 $f^{-1}$。反函数存在的充要条件是 $f$ 为双射（即既是单射又是满射）。直观地说，$f^{-1}$ 将 $f$ 的输出"还原"为原来的输入，满足

$$f^{-1}(f(x)) = x \quad \text{且} \quad f(f^{-1}(y)) = y.$$

在几何上，$y = f^{-1}(x)$ 的图像是 $y = f(x)$ 的图像关于直线 $y = x$ 的对称像。

例题。 求函数 $f(x) = 2x + 3$（定义域 $\mathbb{R}$）的反函数。

解： 令 $y = 2x + 3$，解出 $x$：

$$y - 3 = 2x \implies x = \frac{y - 3}{2}.$$

将 $x$ 与 $y$ 互换，得

$$f^{-1}(x) = \frac{x - 3}{2}.$$

验证：$f^{-1}(f(x)) = \dfrac{(2x+3)-3}{2} = x$ ✓，$f(f^{-1}(x)) = 2\cdot\dfrac{x-3}{2}+3 = x$ ✓。

关键定理（反函数微分法则）。 设 $f$ 在开区间 $I$ 上可微且严格单调，$f^{-1}$ 在对应区间上存在。若 $f'(x) \neq 0$，则 $f^{-1}$ 在 $y = f(x)$ 处可微，且

$$\left(f^{-1}\right)'(y) = \frac{1}{f'(x)}.$$

证明思路： 对恒等式 $f(f^{-1}(y)) = y$ 两边关于 $y$ 求导，由链式法则得 $f'(f^{-1}(y)) \cdot (f^{-1})'(y) = 1$，整理即得结论。$\square$

实验单元（SymPy）。

from sympy import symbols, solve, Function, diff

x, y = symbols('x y')
f_expr = 2*x + 3

# 求反函数
inv_expr = solve(f_expr - y, x)[0]
print("f⁻¹(y) =", inv_expr)          # (y - 3)/2

# 验证微分法则
f_prime = diff(f_expr, x)
inv_prime = diff(inv_expr, y)
print("1/f'(x) =", 1/f_prime)        # 1/2
print("(f⁻¹)'(y) =", inv_prime)      # 1/2

运行结果确认 $(f^{-1})'(y) = 1/f'(x) = 1/2$，与定理完全吻合。
