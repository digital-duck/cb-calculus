斜率

定义。 设平面上两点 $P_1 = (x_1,\, y_1)$ 与 $P_2 = (x_2,\, y_2)$，其中 $x_1 \neq x_2$。直线 $P_1P_2$ 的斜率定义为

$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\Delta y}{\Delta x}.$$

斜率度量直线相对于水平方向的倾斜程度：$m > 0$ 表示直线从左至右上升，$m < 0$ 表示下降，$m = 0$ 表示水平，而垂直线的斜率无定义。对于可微函数 $f$，曲线在点 $x = a$ 处的切线斜率由导数给出：

$$m = f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}.$$

例题。 求抛物线 $f(x) = x^2 - 3x + 2$ 在点 $x = 2$ 处的切线斜率，并写出切线方程。

解。 对 $f$ 求导：

$$f'(x) = 2x - 3.$$

代入 $x = 2$：

$$m = f'(2) = 2(2) - 3 = 1.$$

切点坐标为 $(2,\, f(2)) = (2,\, 0)$。由点斜式得切线方程：

$$y - 0 = 1 \cdot (x - 2) \implies y = x - 2.$$

关键定理（均值定理）。 若函数 $f$ 在闭区间 $[a,b]$ 上连续，在开区间 $(a,b)$ 内可微，则存在 $c \in (a,b)$ 使得

$$f'(c) = \frac{f(b) - f(a)}{b - a}.$$

此定理保证：曲线上某点处的切线斜率必等于连接端点的割线斜率，从而将局部微分信息与整体行为联系起来。

实验单元（SymPy）。

import sympy as sp

x = sp.Symbol('x')
f = x**2 - 3*x + 2

# 在 x=2 处的切线斜率
slope = sp.diff(f, x).subs(x, 2)
print("切线斜率:", slope)          # 输出: 1

# 切线方程
tangent = slope * (x - 2) + f.subs(x, 2)
print("切线方程: y =", sp.expand(tangent))   # 输出: y = x - 2

运行上述代码，验证 $m = 1$ 及切线方程 $y = x - 2$，并尝试将 $x = 2$ 替换为其他点，观察斜率如何随位置变化。
