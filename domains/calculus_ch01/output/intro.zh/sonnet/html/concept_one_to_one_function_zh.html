One To One Function

定义。 设 $f: A \to B$ 为一函数。若对任意 $x_1, x_2 \in A$，

$$x_1 \neq x_2 \implies f(x_1) \neq f(x_2),$$

则称 $f$ 为单射函数（一一函数）。等价地，其逆否命题为：

$$f(x_1) = f(x_2) \implies x_1 = x_2.$$

直观上，单射函数对定义域中每一个不同的输入，均给出不同的输出，即不存在两个不同的自变量映射到同一因变量值。在图形上，这等价于水平线检验：任意水平线 $y = c$ 与函数图像至多有一个交点。

例题。 判断 $f(x) = 2x + 3$（$f: \mathbb{R} \to \mathbb{R}$）是否为单射。

解。 设 $f(x_1) = f(x_2)$，即

$$2x_1 + 3 = 2x_2 + 3.$$

两边同减 $3$，再除以 $2$，得

$$x_1 = x_2.$$

因此，由定义可知 $f$ 为单射函数。$\blacksquare$

再考察 $g(x) = x^2$（$g: \mathbb{R} \to \mathbb{R}$）。取 $x_1 = 2,\ x_2 = -2$，则 $x_1 \neq x_2$，但

$$g(2) = 4 = g(-2),$$

故 $g$ 不是单射函数。若将定义域限制为 $[0, +\infty)$，则 $g$ 成为单射。

关键定理（单射与可逆性）。 设 $f: A \to B$。$f$ 存在左逆（即存在函数 $h: B \to A$ 使得 $h \circ f = \mathrm{id}_A$）当且仅当 $f$ 为单射。

证明思路。 若 $f$ 为单射，对每个 $b \in f(A)$ 恰有唯一 $a \in A$ 满足 $f(a) = b$，故可良定义 $h(b) = a$；对 $b \notin f(A)$ 任意指定值。验证知 $h(f(a)) = a$，即 $h \circ f = \mathrm{id}_A$。反之，若左逆存在，则 $f(x_1)=f(x_2)$ 蕴含 $x_1 = h(f(x_1)) = h(f(x_2)) = x_2$，故 $f$ 为单射。$\square$

实验单元（SymPy）。

from sympy import symbols, solve, Function

x1, x2 = symbols('x1 x2')
f = lambda x: 2*x + 3

# 验证单射：解 f(x1) = f(x2) 是否仅有 x1 = x2
sol = solve(f(x1) - f(x2), x1)
print(sol)  # 期望输出: [x2]
