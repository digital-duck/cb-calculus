Quadratic Function

定义

二次函数（quadratic function）是形如

$$f(x) = ax^2 + bx + c, \quad a, b, c \in \mathbb{R},\ a \neq 0$$

的实值函数，其中 $a$ 称为二次项系数，$b$ 为一次项系数，$c$ 为常数项。条件 $a \neq 0$ 保证函数的最高次项为二次，使其图像为抛物线而非直线。通过配方（completing the square），可将标准形式化为顶点式：

$$f(x) = a\!\left(x - h\right)^2 + k,$$

其中顶点坐标为 $\displaystyle h = -\frac{b}{2a}$，$\displaystyle k = f(h) = c - \frac{b^2}{4a}$。当 $a > 0$ 时抛物线开口向上，$k$ 为最小值；当 $a < 0$ 时开口向下，$k$ 为最大值。

例题

求 $f(x) = 2x^2 - 8x + 3$ 的顶点，并确定其值域。

解：计算

$$h = -\frac{-8}{2 \cdot 2} = 2, \quad k = 2(2)^2 - 8(2) + 3 = 8 - 16 + 3 = -5.$$

故顶点为 $(2,\,-5)$。由于 $a = 2 > 0$，函数在 $x = 2$ 处取最小值 $-5$，值域为 $[-5,\, +\infty)$。

核心定理：二次方程的根

定理（求根公式）。方程 $ax^2 + bx + c = 0$（$a \neq 0$）的根为

$$x = \frac{-b \pm \sqrt{\Delta}}{2a}, \quad \Delta = b^2 - 4ac.$$

判别式 $\Delta$ 决定根的性质：$\Delta > 0$ 时有两个不同实根；$\Delta = 0$ 时有一个重根；$\Delta < 0$ 时无实根（有两个共轭复根）。证明思路：对 $ax^2 + bx + c = 0$ 两边除以 $a$，再配方得 $\bigl(x + \tfrac{b}{2a}\bigr)^2 = \tfrac{\Delta}{4a^2}$，取平方根即得结论。$\blacksquare$

实验单元（SymPy）

from sympy import symbols, solve, factor, discriminant, Rational

x = symbols('x')
f = 2*x**2 - 8*x + 3

# 求根与判别式
roots = solve(f, x)
Delta = discriminant(f, x)
print("根：", roots)
print("判别式 Δ =", Delta)

# 配方（顶点式）
h = Rational(-(-8), 2*2)
k = f.subs(x, h)
print(f"顶点式：2(x - {h})² + {k}")
