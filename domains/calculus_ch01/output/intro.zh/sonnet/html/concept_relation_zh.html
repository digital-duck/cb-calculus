关系

定义． 设 $A$ 与 $B$ 为两个集合。从 $A$ 到 $B$ 的一个二元关系（binary relation）是笛卡尔积 $A \times B$ 的任意子集 $R \subseteq A \times B$。若 $(a, b) \in R$，则记作 $a \mathrel{R} b$，读作"$a$ 与 $b$ 有关系 $R$"。当 $A = B$ 时，称 $R$ 为集合 $A$ 上的关系。

关系是函数概念的推广：函数要求每个输入恰好对应唯一输出，而关系对此不作限制——一个元素可以与多个元素相关，也可以不与任何元素相关。

例题． 设 $A = \{1, 2, 3\}$，定义 $A$ 上的整除关系

$$R = \{(a, b) \in A \times A \mid a \text{ 整除 } b\}.$$

列举所有有序对：$1$ 整除 $1, 2, 3$；$2$ 整除 $2$；$3$ 整除 $3$。故

$$R = \{(1,1),\,(1,2),\,(1,3),\,(2,2),\,(3,3)\}.$$

可验证：$(2, 3) \notin R$，因为 $2 \nmid 3$。

关系的性质． 设 $R$ 为集合 $A$ 上的关系，常见性质定义如下：

| 性质 | 定义 | |------|------| | 自反性 | $\forall a \in A,\ a \mathrel{R} a$ | | 对称性 | $a \mathrel{R} b \Rightarrow b \mathrel{R} a$ | | 传递性 | $a \mathrel{R} b \land b \mathrel{R} c \Rightarrow a \mathrel{R} c$ | | 反对称性 | $a \mathrel{R} b \land b \mathrel{R} a \Rightarrow a = b$ |

同时满足自反性、对称性与传递性的关系称为等价关系；同时满足自反性、反对称性与传递性的关系称为偏序关系。

定理（等价类划分）． 设 $\sim$ 为集合 $A$ 上的等价关系。对每个 $a \in A$，定义等价类 $[a] = \{x \in A \mid x \sim a\}$。则全体等价类构成 $A$ 的一个划分，即：$\bigcup_{a \in A} [a] = A$，且任意两个不同等价类互不相交。

实验单元（SymPy）．

from sympy import FiniteSet
A = FiniteSet(1, 2, 3)
R = [(a, b) for a in A for b in A if b % a == 0]
print("整除关系 R =", R)

# 验证传递性
transitive = all(
    (a, c) in R
    for (a, b) in R for (b2, c) in R if b == b2
)
print("传递性成立:", transitive)

运行上述代码，可观察到 $R$ 满足自反性与传递性，但不满足对称性（因 $(1,2) \in R$ 而 $(2,1) \notin R$），从而确认整除关系是 $A$ 上的偏序关系。
