里氏震级应用将本书所建立的全部数学工具——对数函数、指数增长、量级比较——汇聚于一个真实的科学情境之中。它不是抽象理论的终点，而是一扇门：通过它，读者第一次看见纯粹数学如何直接决定人类对自然灾害的理解与响应。这正是本书的自然终点，因为里氏震级既要求精确的数学定义，又要求对量级直觉的深刻把握，二者缺一不可。

定义：设地震波在标准距离处的振幅为 $A$，参考振幅为 $A_0$（对应震级为零的基准地震），则里氏震级定义为

$$M = \log_{10}\!\left(\frac{A}{A_0}\right).$$

这一定义的核心在于对数压缩：振幅每增大十倍，震级仅增加一级。因此震级之差 $\Delta M$ 对应能量之比 $10^{1.5\,\Delta M}$，即震级相差两级的地震，能量相差约一千倍。

例题：设地震甲的振幅为 $A_1 = 10^4 A_0$，地震乙的振幅为 $A_2 = 10^6 A_0$。求两者震级及其能量之比。

$$M_1 = \log_{10}(10^4) = 4,\quad M_2 = \log_{10}(10^6) = 6.$$

能量之比为 $10^{1.5\times(6-4)} = 10^3 = 1000$。即乙的能量是甲的一千倍，尽管振幅仅相差百倍。

关键定理：对任意两次地震，震级差 $\Delta M = M_2 - M_1$ 与振幅比的关系为

$$\frac{A_2}{A_1} = 10^{\Delta M},$$

与能量比的关系为

$$\frac{E_2}{E_1} = 10^{1.5\,\Delta M}.$$

此定理揭示了对数尺度在物理量压缩中的核心作用，是声学分贝、天文星等、信息熵等一切对数量级的共同数学骨架。

实验单元（SymPy）：

from sympy import log, Rational, symbols, simplify
A1, A2, A0 = 1e4, 1e6, 1
M1 = log(A1/A0, 10)
M2 = log(A2/A0, 10)
energy_ratio = 10**(Rational(3,2)*(M2 - M1))
print(f"震级差：{M2 - M1}，能量之比：{energy_ratio}")

里氏震级将读者引向更广阔的应用疆域：声学中的分贝计算、天文学中的星等体系、信息论中的熵度量，乃至金融学中的对数收益率，皆是同一数学结构在不同物理背景下的投影。
