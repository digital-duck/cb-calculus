Exponential Function

定义

指数函数是形如

$$f(x) = a^x, \quad a > 0,\; a \neq 1$$

的函数，其中 $a$ 称为底数，$x$ 为实数指数。当底数取自然常数 $e \approx 2.71828$ 时，得到自然指数函数 $f(x) = e^x$，它在分析学中占据核心地位。指数函数的定义域为 $\mathbb{R}$，值域为 $(0, +\infty)$；函数图像过点 $(0, 1)$，当 $a > 1$ 时单调递增，当 $0 < a < 1$ 时单调递减。

基本性质

指数函数满足以下运算律：

$$a^{x+y} = a^x \cdot a^y, \qquad a^{xy} = (a^x)^y, \qquad a^0 = 1.$$

这些性质将乘法运算转化为加法运算，是对数函数存在的根本原因。

例题

问题： 求解方程 $2^{2x-1} = 32$。

解： 将右侧改写为 $2$ 的幂次：

$$32 = 2^5.$$

因此原方程化为

$$2x - 1 = 5 \implies x = 3.$$

验证：$2^{2(3)-1} = 2^5 = 32$，成立。$\blacksquare$

核心定理

定理（自然指数函数的导数）。 设 $f(x) = e^x$，则对一切 $x \in \mathbb{R}$，有

$$f'(x) = e^x.$$

证明要点： 由导数定义，

$$f'(x) = \lim_{h \to 0} \frac{e^{x+h} - e^x}{h} = e^x \lim_{h \to 0} \frac{e^h - 1}{h}.$$

利用极限 $\displaystyle\lim_{h \to 0} \frac{e^h - 1}{h} = 1$（可由 $e$ 的级数定义严格证明），立得 $f'(x) = e^x$。这一性质说明自然指数函数是以自身为导数的唯一（在差一个常数倍意义下）函数，使其成为微分方程的天然解。$\square$

实验单元（SymPy）

from sympy import *
x = symbols('x')

# 定义自然指数函数并求导
f = exp(x)
print("f(x)  =", f)
print("f'(x) =", diff(f, x))          # 应输出 exp(x)

# 求解指数方程 2^(2x-1) = 32
eq = Eq(2**(2*x - 1), 32)
print("解：x =", solve(eq, x))        # 应输出 [3]

# 绘制 e^x 在 [-2, 2] 上的图像
plot(exp(x), (x, -2, 2), title='f(x) = e^x', ylabel='f(x)')

运行上述代码，可验证导数公式与方程求解结果，并直观观察指数增长的急剧态势。
