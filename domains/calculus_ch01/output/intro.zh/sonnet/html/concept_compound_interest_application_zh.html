Compound Interest Application

定义

复利（Compound Interest）是指利息在每个计息周期结束后被并入本金，从而在下一周期产生新的利息的一种计算方式。设初始本金为 $P$，年利率为 $r$，每年计息 $n$ 次，经过 $t$ 年后，账户总额 $A$ 由以下公式给出：

$$A = P \left(1 + \frac{r}{n}\right)^{nt}$$

当计息频率趋于无穷大时，即 $n \to \infty$，上式收敛至连续复利公式：

$$A = Pe^{rt}$$

其中 $e \approx 2.71828$ 为自然常数。这一极限由数学分析中的基本极限 $\lim_{n \to \infty}\left(1 + \frac{1}{n}\right)^n = e$ 直接推导而来。

典型例题

设某人将 $P = 10{,}000$ 元存入年利率 $r = 6\%$ 的账户，计息方式为每季度一次（即 $n = 4$），求 $t = 5$ 年后的账户总额。

代入公式：

$$A = 10{,}000 \times \left(1 + \frac{0.06}{4}\right)^{4 \times 5} = 10{,}000 \times (1.015)^{20}$$

计算得 $(1.015)^{20} \approx 1.3469$，故：

$$A \approx 13{,}469 \text{ 元}$$

若改用连续复利，则 $A = 10{,}000 \cdot e^{0.06 \times 5} = 10{,}000 \cdot e^{0.3} \approx 13{,}499$ 元。两者相差约 $30$ 元，体现了连续计息的理论上界。

核心定理

定理（复利增长的指数本质）：对固定年利率 $r > 0$，复利函数 $A(t) = Pe^{rt}$ 满足一阶线性常微分方程

$$\frac{dA}{dt} = rA, \quad A(0) = P$$

这意味着账户余额的瞬时增长率始终正比于当前余额本身——这正是指数增长的特征方程。其解的唯一性由常微分方程的存在唯一性定理保证。

实验单元（SymPy）

from sympy import symbols, exp, simplify, limit, oo

P, r, n, t = symbols('P r n t', positive=True)

# 离散复利公式
A_discrete = P * (1 + r/n)**(n*t)

# 验证连续复利极限
A_continuous = limit(A_discrete, n, oo)
print("连续复利公式：", simplify(A_continuous))  # 期望输出：P*exp(r*t)

# 数值验证
from sympy import N
result = N(A_continuous.subs({P: 10000, r: 0.06, t: 5}))
print("连续复利终值：", result)

运行上述代码，学生可验证极限推导的正确性，并直观感受离散与连续计息之间的微小差异。
