Relation

A relation between two sets $A$ and $B$ is any subset of the Cartesian product $A \times B$ — that is, a collection of ordered pairs $(a, b)$ where $a \in A$ and $b \in B$. When $A = B$, we say the relation is on $A$. Relations are the foundation for functions, orderings, and equivalence classes, so getting comfortable with them unlocks a wide swath of mathematics and computer science.

The notation $a \mathrel{R} b$ means the pair $(a, b)$ belongs to the relation $R$. Four key properties determine what kind of relation you have:

  • Reflexive: every element relates to itself — $a \mathrel{R} a$ for all $a \in A$.
  • Symmetric: if $a \mathrel{R} b$ then $b \mathrel{R} a$.
  • Antisymmetric: if $a \mathrel{R} b$ and $b \mathrel{R} a$ then $a = b$.
  • Transitive: if $a \mathrel{R} b$ and $b \mathrel{R} c$ then $a \mathrel{R} c$.

    • A relation that is reflexive, symmetric, and transitive is an equivalence relation; it partitions $A$ into disjoint equivalence classes. A relation that is reflexive, antisymmetric, and transitive is a partial order.

    Worked example. Let $A = \{1, 2, 3, 4, 6, 12\}$ and define $a \mathrel{R} b$ to mean "$a$ divides $b$." Check the properties: $a \mid a$ always, so it is reflexive. If $a \mid b$ and $b \mid a$ then $a = b$ (for positive integers), so it is antisymmetric. Divisibility chains ($a \mid b$ and $b \mid c$ imply $a \mid c$), so it is transitive. This makes $R$ a partial order — specifically the divisibility order on $A$.

    Applying it. Suppose you are designing a course prerequisite system. Courses are nodes; draw an edge from course $X$ to course $Y$ whenever $X$ must be completed before $Y$. This is a relation on the set of courses. Checking transitivity tells you whether the system is logically consistent (if Calculus I precedes Calculus II and Calculus II precedes Differential Equations, does Calculus I automatically precede Differential Equations?). Checking for cycles detects circular prerequisites — an impossible curriculum. Recognizing the relation as a partial order (reflexive, antisymmetric, transitive, with no cycles) immediately tells you the schedule can be linearized via topological sort, giving a valid enrollment sequence. Understanding the relation's structure turns a fuzzy administrative problem into a solvable graph algorithm.
