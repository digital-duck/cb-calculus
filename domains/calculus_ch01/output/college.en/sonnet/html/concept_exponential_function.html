Exponential Function

Definition. An exponential function has the form $f(x) = a \cdot b^x$, where $a$ is the initial value, $b > 0$ is the base, and $x$ is the exponent. The defining feature is that the input is in the exponent — which makes the function grow (or decay) by a constant multiplicative factor for every unit increase in $x$. When $b > 1$ the function grows; when $0 < b < 1$ it decays. The natural exponential $f(x) = e^x$, where $e \approx 2.71828$, appears throughout science because it is its own derivative — the rate of change equals the current value.

Worked example. A colony of bacteria doubles every 3 hours. You start with 500 cells. How many cells are there after 12 hours?

The doubling period is 3 hours, so after $t$ hours the number of doublings is $t/3$. The population model is:

$$P(t) = 500 \cdot 2^{t/3}$$

At $t = 12$:

$$P(12) = 500 \cdot 2^{12/3} = 500 \cdot 2^4 = 500 \cdot 16 = 8{,}000$$

Notice the mechanics: each 3-hour interval multiplies the population by 2, regardless of how large it already is. That multiplicative consistency is what makes the function exponential.

Problem-solving application. Exponential functions appear whenever a quantity changes proportionally to its current size — compound interest, radioactive decay, viral spread, drug clearance. The key problem-solving move is identifying the base and the period.

For compound interest, $A = P\left(1 + \frac{r}{n}\right)^{nt}$, the base is $(1 + r/n)$ and each compounding period multiplies the balance by that factor. For radioactive decay with half-life $h$, the base is $1/2$ and the period is $h$:

$$N(t) = N_0 \cdot \left(\frac{1}{2}\right)^{t/h}$$

A practical check: if the ratio $P(t+k)/P(t)$ is constant for all $t$, the relationship is exponential. If that ratio keeps changing, look for a different model (polynomial, logistic, etc.). Plotting data on a log scale turns an exponential into a straight line — a quick visual test that practitioners use before fitting any model.
