Function

A function is a rule that assigns to each input exactly one output. More precisely, a function $f$ from a set $A$ to a set $B$, written $f: A \to B$, maps every element $x \in A$ to a unique element $f(x) \in B$. The set $A$ is the domain and $B$ is the codomain. The collection of all actual outputs is the range (a subset of the codomain). The "exactly one output" condition is the defining constraint: a relation that maps a single input to two different outputs is not a function.

Functions appear everywhere in mathematics and computing — from $f(x) = x^2$ mapping real numbers to their squares, to a Python function that takes a string and returns its length. The idea is identical in both cases: deterministic, one-to-one-output mapping.

Worked example. Let $f(x) = 2x + 3$ with domain $\mathbb{R}$.

  • Evaluate: $f(4) = 2(4) + 3 = 11$.
  • Find the input that gives output $15$: solve $2x + 3 = 15 \Rightarrow x = 6$.
  • Determine the range: since $f$ is linear with nonzero slope, the range is all of $\mathbb{R}$.

    • Now consider $g(x) = \sqrt{x - 1}$. The domain is restricted to $x \geq 1$ (so the square root is defined in $\mathbb{R}$), and the range is $[0, \infty)$.

    Problem-solving application. Suppose a phone plan charges a \$20 base fee plus \$0.05 per text message. Define $C(n) = 20 + 0.05n$, where $n$ is the number of texts and $C$ is the monthly cost in dollars.

  • What is the cost for 300 texts? $C(300) = 20 + 0.05(300) = \$35$.
  • You have a \$50 budget. What is the maximum number of texts? Solve $20 + 0.05n \leq 50 \Rightarrow n \leq 600$.
  • Is $C$ a function? Yes — each value of $n$ produces exactly one cost.

    • The same reasoning applies when writing code. A function in Python or any language should ideally behave like a mathematical function: given the same input, it always returns the same output. When a function's output depends on hidden state or side effects, tracing and debugging become significantly harder — recognizing this connection between mathematical and programmatic functions is a powerful mental model.
