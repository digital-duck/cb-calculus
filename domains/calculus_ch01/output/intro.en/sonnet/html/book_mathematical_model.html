What a mathematical model achieves. Every chapter in this book has built toward a single idea: that a real-world system can be represented by a precisely defined mathematical object whose internal logic mirrors the causal structure of the system itself. A mathematical model of a system $\mathcal{S}$ is a triple $\mathcal{M} = (V, \mathcal{F}, \Omega)$, where $V$ is a set of variables encoding observable state, $\mathcal{F}$ is a family of relations or operators (algebraic, differential, probabilistic) governing how those variables evolve or co-vary, and $\Omega$ is the parameter space whose points individuate specific instances of the system. The power of this structure is that deduction within $\mathcal{M}$ corresponds to prediction about $\mathcal{S}$: a theorem proved inside the model yields a testable claim about the world.

Worked example. Consider a population of bacteria with count $N(t)$. Setting $V = \{N\}$, $\mathcal{F} = \{dN/dt = rN\}$, and $\Omega = \{r \in \mathbb{R}_{>0}\}$ produces the Malthusian growth model. Its unique solution $N(t) = N_0 e^{rt}$ is not an empirical guess; it is a logical consequence of the model's axioms. Fitting $r$ to data calibrates $\Omega$ to the specific organism; every subsequent prediction—doubling time $t_2 = \ln 2 / r$, population at any future instant—follows from algebra alone.

Key theorem (Model–Reality correspondence). Let $\mathcal{M}$ be a well-posed model and let $\hat{\omega} \in \Omega$ be the maximum-likelihood parameter estimate obtained from data $\mathbf{y}$. Under standard regularity conditions, the prediction error $\|\mathcal{F}(\hat{\omega})(t) - \mathbb{E}[\mathbf{y}(t)]\|$ converges to zero as the data size grows, and the confidence region for $\hat{\omega}$ shrinks at rate $O(n^{-1/2})$. This guarantees that a correctly specified model becomes an increasingly faithful surrogate for the real system as evidence accumulates.

Lab cell.

from sympy import symbols, Function, dsolve, Eq, exp, solve

t, r, N0 = symbols('t r N0', positive=True)
N = Function('N')
ode = Eq(N(t).diff(t), r * N(t))
sol = dsolve(ode, ics={N(0): N0})
doubling_time = solve(sol.rhs - 2*N0, t)[0]
print(sol)           # N(t) = N0*exp(r*t)
print(doubling_time) # log(2)/r
