Exponential Function

Definition. Let $b > 0$ with $b \neq 1$. The exponential function with base $b$ is the function $f : \mathbb{R} \to (0, \infty)$ defined by

$$f(x) = b^x.$$

The most important special case is $b = e$, where $e = \lim_{n \to \infty}\left(1 + \tfrac{1}{n}\right)^n \approx 2.71828\ldots$ is Euler's number. The function $\exp(x) = e^x$ is distinguished by the property that it is its own derivative: $\tfrac{d}{dx}e^x = e^x$, making it the unique solution to the initial-value problem $y' = y,\ y(0) = 1$.

For $b > 1$ the function is strictly increasing; for $0 < b < 1$ it is strictly decreasing. In both cases the horizontal axis is a horizontal asymptote as $x \to -\infty$ (when $b > 1$) or $x \to +\infty$ (when $b < 1$), and the $y$-intercept is always $f(0) = b^0 = 1$.

Worked Example. A bacterial culture begins with $500$ cells and doubles every $3$ hours. Express the population $P(t)$ after $t$ hours and find $P(9)$.

The doubling period gives base $b = 2$ and rate $t/3$ doublings per hour, so

$$P(t) = 500 \cdot 2^{t/3}.$$

At $t = 9$: $P(9) = 500 \cdot 2^{9/3} = 500 \cdot 2^3 = 500 \cdot 8 = 4000$ cells. Equivalently, writing $k = \tfrac{\ln 2}{3}$, one obtains $P(t) = 500\,e^{kt}$, illustrating that every exponential function can be re-expressed in base $e$.

Key Theorem (Laws of Exponents). For any $b > 0$, $b \neq 1$, and all $x, y \in \mathbb{R}$:

$$b^{x+y} = b^x b^y, \qquad b^{xy} = (b^x)^y, \qquad b^0 = 1.$$

These identities, combined with continuity, uniquely characterize the exponential function among measurable functions satisfying $f(x+y) = f(x)f(y)$.

Lab Cell.

from sympy import symbols, exp, ln, simplify, plot

x = symbols('x', real=True)

# Verify the functional equation b^(x+y) = b^x * b^y with b = e
y = symbols('y', real=True)
lhs = exp(x + y)
rhs = exp(x) * exp(y)
print(simplify(lhs - rhs))   # expects 0

# Bacterial growth model
t = symbols('t', nonneg=True)
P = 500 * exp(ln(2) / 3 * t)
print(P.subs(t, 9))          # expects 4000

plot(exp(x), (x, -3, 3), ylabel='exp(x)')
