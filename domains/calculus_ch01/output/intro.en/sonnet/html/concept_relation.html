Relation

Definition. Let $A$ and $B$ be sets. A binary relation from $A$ to $B$ is any subset $R \subseteq A \times B$ of the Cartesian product. When $A = B$ we call $R$ a relation on $A$. We write $a \mathrel{R} b$ as shorthand for $(a, b) \in R$.

A relation on $A$ may satisfy one or more structural properties. It is reflexive if $a \mathrel{R} a$ for every $a \in A$; symmetric if $a \mathrel{R} b$ implies $b \mathrel{R} a$; antisymmetric if $a \mathrel{R} b$ and $b \mathrel{R} a$ together imply $a = b$; and transitive if $a \mathrel{R} b$ and $b \mathrel{R} c$ imply $a \mathrel{R} c$. These four properties are the building blocks from which all standard relations are assembled.

Worked example. Let $A = \{1, 2, 3, 6\}$ and define $R = \{(a,b) \mid a \text{ divides } b\}$. Listing all pairs explicitly:

$$R = \{(1,1),(1,2),(1,3),(1,6),(2,2),(2,6),(3,3),(3,6),(6,6)\}.$$

Checking properties: every element divides itself, so $R$ is reflexive. If $a \mid b$ and $b \mid a$ with $a, b \in A$, then $a = b$, so $R$ is antisymmetric. If $a \mid b$ and $b \mid c$ then $a \mid c$, so $R$ is transitive. Because $2 \mid 6$ but $6 \nmid 2$, symmetry fails. A reflexive, antisymmetric, transitive relation is called a partial order; the divisibility relation is the canonical example.

Theorem (Equivalence-relation partition). A relation $R$ on $A$ is an equivalence relation — reflexive, symmetric, and transitive — if and only if it partitions $A$ into disjoint, non-empty equivalence classes $[a] = \{b \in A \mid a \mathrel{R} b\}$ whose union is $A$.

Proof sketch. Given an equivalence relation, define $[a]$ as above. Reflexivity ensures $a \in [a]$, so every element belongs to some class. If $[a] \cap [b] \neq \emptyset$, pick $c$ in both; by symmetry and transitivity every element of $[a]$ is in $[b]$ and vice versa, so $[a] = [b]$. The converse follows by reading these steps in reverse. $\square$

from sympy import divisors
A = [1, 2, 3, 6]
R = [(a, b) for a in A for b in A if b % a == 0]
reflexive    = all((a, a) in R for a in A)
antisymmetric = all(a == b for (a, b) in R if (b, a) in R)
transitive   = all((a, c) in R for (a, b) in R for (c, d) in R if b == c)
print(reflexive, antisymmetric, transitive)   # True True True
