Inverse Function

Definition. Let $f : A \to B$ be a function. We say $f$ is invertible if there exists a function $g : B \to A$ such that

$$g(f(x)) = x \quad \text{for all } x \in A, \qquad \text{and} \qquad f(g(y)) = y \quad \text{for all } y \in B.$$

When such a $g$ exists it is unique, and we denote it $f^{-1}$. A function is invertible if and only if it is bijective — that is, both injective (one-to-one) and surjective (onto). Geometrically, the graph of $f^{-1}$ is the reflection of the graph of $f$ across the line $y = x$.

Worked Example. Consider $f : \mathbb{R} \to \mathbb{R}^{+}$ defined by $f(x) = e^x$. To find $f^{-1}$, set $y = e^x$ and solve for $x$:

$$y = e^x \implies x = \ln y.$$

Hence $f^{-1}(y) = \ln y$, i.e.\ the natural logarithm is the inverse of the exponential. We verify both composition conditions:

$$f^{-1}(f(x)) = \ln(e^x) = x, \qquad f(f^{-1}(y)) = e^{\ln y} = y. \checkmark$$

Note that $f$ is bijective on the stated domain and codomain, which is why the inverse exists globally.

Key Theorem (Inverse Function Theorem). Let $f$ be continuously differentiable on an open interval containing $a$, with $f'(a) \neq 0$. Then $f$ is locally invertible near $a$, and

$$\left(f^{-1}\right)'(b) = \frac{1}{f'(a)}, \qquad \text{where } b = f(a).$$

Proof sketch. The condition $f'(a) \neq 0$ guarantees, via the implicit function theorem, that the equation $f(x) - b = 0$ can be solved uniquely for $x$ near $a$. Differentiating the identity $f(f^{-1}(y)) = y$ with respect to $y$ and applying the chain rule yields the derivative formula directly.

Lab Cell (SymPy).

import sympy as sp

x = sp.Symbol('x', positive=True)
f = sp.exp(x)
f_inv = sp.ln(x)

# verify compositions
print(sp.simplify(f_inv.subs(x, f)))   # expects x
print(sp.simplify(f.subs(x, f_inv)))   # expects x

# derivative of inverse at a point
a = sp.Symbol('a', positive=True)
deriv_inv = 1 / sp.diff(f, x).subs(x, a)
print(deriv_inv)                        # expects exp(-a)
