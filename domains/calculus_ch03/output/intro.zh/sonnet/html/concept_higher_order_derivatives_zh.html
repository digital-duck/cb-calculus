Higher Order Derivatives

定义。 设函数 $f$ 在开区间 $I$ 上可微，其导函数 $f'$ 仍为 $I$ 上的函数。若 $f'$ 在某点 $x$ 处可微，则称该导数为 $f$ 的二阶导数，记作

$$f''(x) = \frac{d^2f}{dx^2} = \frac{d}{dx}\!\left(\frac{df}{dx}\right).$$

一般地，$f$ 的 $n$ 阶导数递归定义为

$$f^{(n)}(x) = \frac{d}{dx}f^{(n-1)}(x), \quad n \geq 1,$$

其中约定 $f^{(0)} = f$。称 $f$ 在 $I$ 上 $n$ 次可微，若 $f^{(n)}$ 在 $I$ 上处处存在。

例题。 求 $f(x) = x^4 - 3x^2 + 2x$ 的各阶导数，并确定何时高阶导数恒为零。

逐阶求导：

$$f'(x) = 4x^3 - 6x + 2,$$ $$f''(x) = 12x^2 - 6,$$ $$f'''(x) = 24x,$$ $$f^{(4)}(x) = 24,$$ $$f^{(n)}(x) = 0, \quad n \geq 5.$$

由此可见，$n$ 次多项式的第 $n+1$ 阶及更高阶导数恒为零。$f''(x) = 12x^2 - 6$ 的零点为 $x = \pm\tfrac{1}{\sqrt{2}}$，这两点正是 $f$ 的拐点所在位置，即凹凸性发生改变之处。

关键定理（Taylor 展开的局部形式）。 设 $f$ 在 $x = a$ 处 $n$ 次可微，则

$$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k + o\!\left((x-a)^n\right), \quad x \to a.$$

此定理表明，高阶导数完整刻画了函数在一点附近的局部行为：$f^{(n)}(a)$ 控制着 $(x-a)^n$ 项的系数，从而决定曲线的弯曲程度与高阶振荡特征。

实验单元（SymPy）。

import sympy as sp

x = sp.Symbol('x')
f = x**4 - 3*x**2 + 2*x

for n in range(6):
    dn = sp.diff(f, x, n)
    print(f"f^({n}) =", dn)

# 求 f'' 的零点（拐点候选）
inflections = sp.solve(sp.diff(f, x, 2), x)
print("拐点候选 x =", inflections)

运行后观察：随着求导阶数增加，多项式次数逐步降低，直至为零。修改 $f$ 为 $\sin x$ 或 $e^x$，体会无穷次可微函数的周期性与自相似性。
