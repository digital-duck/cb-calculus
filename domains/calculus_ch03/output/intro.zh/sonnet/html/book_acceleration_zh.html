加速度的意义与自然终点

在微积分的概念阶梯上，位移描述"在哪里"，速度描述"变化多快"，而加速度则揭示"变化本身如何变化"。设质点的位置函数为 $x(t)$，则速度定义为 $v(t) = \dfrac{dx}{dt}$，加速度定义为：

$$a(t) = \frac{dv}{dt} = \frac{d^2x}{dt^2}.$$

加速度是位置关于时间的二阶导数，它捕捉了运动状态改变的根本原因。牛顿第二定律 $F = ma$ 表明：力不直接决定位置，也不直接决定速度，而是通过加速度驱动整个运动过程。这正是为什么加速度是经典力学的自然终点——理解了它，就掌握了从力到轨迹的完整因果链。

具体示例

设质点做自由落体运动，取向下为正方向，忽略空气阻力，则

$$a(t) = g \approx 9.8 \text{ m/s}^2.$$

对加速度积分一次得速度 $v(t) = g t + v_0$，再积分一次得位移 $x(t) = \tfrac{1}{2}g t^2 + v_0 t + x_0$。若一块石子从静止（$v_0=0$，$x_0=0$）开始下落，问 $t=3\text{ s}$ 时速度与位移各为多少？

$$v(3) = 9.8 \times 3 = 29.4 \text{ m/s},\quad x(3) = \tfrac{1}{2}\times 9.8\times 9 = 44.1 \text{ m}.$$

核心定理

运动学基本定理：若加速度 $a(t)$ 在 $[t_0, t]$ 上连续，则

$$v(t) = v(t_0) + \int_{t_0}^{t} a(\tau)\,d\tau, \qquad x(t) = x(t_0) + \int_{t_0}^{t} v(\tau)\,d\tau.$$

由此，只要给定初始条件与加速度函数，质点的完整运动轨迹即可唯一确定。

实验单元（SymPy）

import sympy as sp
t = sp.Symbol('t')
a = sp.Rational(98, 10)          # 9.8 m/s²
v = sp.integrate(a, t)           # 速度
x = sp.integrate(v, t)           # 位移
print(sp.simplify(x))            # 4.9*t**2

探索邀请

加速度的概念远不止于落体。在振动分析中，弹簧-质量系统满足 $a = -\omega^2 x$，由此导出简谐运动的全部规律；在信号处理中，加速度计测量的时间序列可还原出设备的完整运动状态；在经济学中，通货膨胀率的加速度反映货币政策的即时效力。若你对其中某一领域充满好奇，不妨从下一章的简谐振子开始——那里，加速度将化身为宇宙中最普遍的节律。
