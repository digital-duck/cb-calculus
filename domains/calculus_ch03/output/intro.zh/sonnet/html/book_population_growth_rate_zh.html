收益

种群增长率（population growth rate）是本教材所有先行概念的自然汇聚点。从极限的严格定义，到导数的线性近似，再到微分方程的定性分析，每一层抽象都在为理解"变化的速率如何决定系统的命运"铺垫。种群增长率将这一抽象还原为最具说服力的具体形式：生命数量随时间的演化规律。

定义。 设 $N(t)$ 为时刻 $t$ 的种群数量，则瞬时增长率定义为

$$r(t) = \frac{1}{N(t)}\frac{dN}{dt},$$

即单位个体对种群变化的贡献速率。当 $r$ 为常数时，方程 $\frac{dN}{dt} = rN$ 的解为指数函数 $N(t) = N_0 e^{rt}$；当 $r$ 依赖于 $N$ 本身时（例如 Logistic 模型 $r(N) = r_0\bigl(1 - N/K\bigr)$），系统便展现出饱和、平衡与崩溃等丰富行为。

算例。 设某细菌培养液在 $t=0$ 时有 $N_0 = 500$ 个细胞，经测定 $r = 0.35\ \text{h}^{-1}$，环境容纳量 $K = 10{,}000$。Logistic 方程给出

$$N(t) = \frac{K}{1 + \left(\frac{K - N_0}{N_0}\right)e^{-r_0 t}}.$$

代入数值，$t = 10\ \text{h}$ 时 $N \approx 3{,}310$，增长速率 $dN/dt = r_0 N(1-N/K) \approx 773\ \text{个·h}^{-1}$，种群仍处于加速增长阶段。

关键定理（平衡稳定性判据）。 对自治方程 $\frac{dN}{dt} = f(N)$，平衡点 $N^$（满足 $f(N^)=0$）为渐近稳定，当且仅当 $f'(N^) < 0$。对 Logistic 模型，$f'(K) = -r_0 < 0$，故 $N^ = K$ 是稳定平衡；$f'(0) = r_0 > 0$，故 $N^* = 0$ 不稳定。

# 实验单元：用 SymPy 验证平衡稳定性
from sympy import *

N, r0, K, t = symbols('N r0 K t', positive=True)
f = r0 * N * (1 - N / K)

equilibria = solve(f, N)          # [0, K]
stability  = [diff(f, N).subs(N, eq).simplify() for eq in equilibria]
print(equilibria)   # [0, K]
print(stability)    # [r0, -r0]  → 0 不稳定，K 稳定
