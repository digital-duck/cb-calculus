Multivariable Calculus

Single-variable calculus asks how a function changes along one axis. Multivariable calculus extends that question to functions of two or more inputs — the kind that describe almost every real system. Temperature across a metal plate, profit as a function of price and quantity, the elevation of a mountain terrain — all depend on several variables simultaneously.

The central tool: partial derivatives. For a function $f(x, y)$, the partial derivative $\frac{\partial f}{\partial x}$ measures the rate of change in the $x$-direction while holding $y$ fixed. Formally,

$$\frac{\partial f}{\partial x} = \lim_{h \to 0} \frac{f(x+h,\, y) - f(x,\, y)}{h}$$

and $\frac{\partial f}{\partial y}$ is defined symmetrically. Both are computed with ordinary differentiation rules — you just treat the other variable as a constant.

Worked example. Let $f(x, y) = 3x^2 y + y^3$. Compute the partial derivatives.

$$\frac{\partial f}{\partial x} = 6xy, \qquad \frac{\partial f}{\partial y} = 3x^2 + 3y^2$$

The gradient $\nabla f = \left\langle \frac{\partial f}{\partial x},\, \frac{\partial f}{\partial y} \right\rangle = \langle 6xy,\; 3x^2 + 3y^2 \rangle$ packages both partial derivatives into a vector that points in the direction of steepest increase.

Applying it: optimization. To find local extrema of $f(x, y)$, set both partial derivatives to zero and solve the resulting system — this is the multivariable analogue of setting $f'(x) = 0$.

Find the critical points of $g(x, y) = x^2 + y^2 - 4x - 6y + 13$.

$$\frac{\partial g}{\partial x} = 2x - 4 = 0 \;\Rightarrow\; x = 2$$ $$\frac{\partial g}{\partial y} = 2y - 6 = 0 \;\Rightarrow\; y = 3$$

The single critical point is $(2, 3)$. Since $g$ is a paraboloid opening upward, this is a global minimum: $g(2, 3) = 0$.

Why this matters. Gradient descent — the engine behind neural network training — is multivariable calculus in action: compute $\nabla f$ at the current point, step in the direction $-\nabla f$, repeat. Every modern machine learning library computes partial derivatives automatically using this same mathematical foundation. Mastering partial derivatives and gradients gives you direct access to how optimization works under the hood.
