面积问题

定义。 设 $f:[a,b]\to\mathbb{R}$ 为非负连续函数。所谓面积问题，是指求曲线 $y=f(x)$、直线 $x=a$、$x=b$ 与 $x$ 轴所围成平面区域的面积 $A$。这一问题是积分学的核心出发点，其严格解答依赖于黎曼和的极限过程。

将区间 $[a,b]$ 等分为 $n$ 个子区间，每段长度为 $\Delta x = \dfrac{b-a}{n}$。在第 $i$ 个子区间 $[x_{i-1}, x_i]$ 上取样本点 $x_i^ $，以 $f(x_i^)$ 为高、$\Delta x$ 为宽构造矩形，则 $n$ 个矩形面积之和称为黎曼和：

$$S_n = \sum_{i=1}^{n} f(x_i^*)\,\Delta x.$$

当 $n\to\infty$ 时，若此和趋于有限极限且与样本点的选取无关，则该极限即为所求面积：

$$A = \lim_{n\to\infty} S_n = \int_a^b f(x)\,dx.$$

具体例子。 求抛物线 $f(x)=x^2$ 在 $[0,1]$ 上与 $x$ 轴围成的面积。取右端点 $x_i^* = \dfrac{i}{n}$，则

$$S_n = \sum_{i=1}^{n}\left(\frac{i}{n}\right)^2\cdot\frac{1}{n} = \frac{1}{n^3}\sum_{i=1}^{n}i^2 = \frac{1}{n^3}\cdot\frac{n(n+1)(2n+1)}{6}.$$

化简得 $S_n = \dfrac{(n+1)(2n+1)}{6n^2}$，当 $n\to\infty$ 时趋于 $\dfrac{1}{3}$，故 $A=\dfrac{1}{3}$。

关键定理（黎曼可积性）。 若 $f$ 在 $[a,b]$ 上连续，则 $f$ 在该区间上黎曼可积，即极限 $\displaystyle\lim_{n\to\infty}S_n$ 存在且唯一，与子区间划分方式及样本点选取无关。

实验单元。 以下 SymPy 代码验证上述结论：

from sympy import *
x, n, i = symbols('x n i', positive=True)

# 符号求和验证黎曼和极限
riemann = summation((i/n)**2 * (1/n), (i, 1, n))
print("黎曼和 =", simplify(riemann))
print("极限   =", limit(riemann, n, oo))

# 直接积分
print("定积分 =", integrate(x**2, (x, 0, 1)))

运行结果应输出黎曼和极限与定积分均为 $\dfrac{1}{3}$，从而在计算层面印证黎曼定义的自洽性。
