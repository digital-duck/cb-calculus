微分学

定义

设函数 $f$ 在点 $x_0$ 的某邻域内有定义。若极限

$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

存在且有限，则称 $f$ 在 $x_0$ 处可微，该极限值称为 $f$ 在 $x_0$ 处的导数（derivative）。几何上，$f'(x_0)$ 即曲线 $y = f(x)$ 在点 $(x_0, f(x_0))$ 处切线的斜率；物理上，若 $f(t)$ 表示位移，则 $f'(t)$ 表示瞬时速度。微分 $\mathrm{d}f = f'(x)\,\mathrm{d}x$ 给出函数在无穷小变化 $\mathrm{d}x$ 下的线性近似。

例题

求 $f(x) = x^3 - 2x$ 在 $x_0 = 1$ 处的导数，并写出切线方程。

由定义，

$$f'(x) = \lim_{\Delta x \to 0} \frac{(x+\Delta x)^3 - 2(x+\Delta x) - x^3 + 2x}{\Delta x}.$$

展开分子：$(x+\Delta x)^3 = x^3 + 3x^2\Delta x + 3x(\Delta x)^2 + (\Delta x)^3$，化简后分子变为 $(3x^2 - 2)\Delta x + O((\Delta x)^2)$，除以 $\Delta x$ 并令 $\Delta x \to 0$，得

$$f'(x) = 3x^2 - 2.$$

故 $f'(1) = 3(1)^2 - 2 = 1$，切点为 $(1, -1)$，切线方程为 $y = x - 2$。

关键定理

链式法则：若 $g$ 在 $x$ 处可微，$f$ 在 $g(x)$ 处可微，则复合函数 $h = f \circ g$ 在 $x$ 处可微，且

$$h'(x) = f'\!\bigl(g(x)\bigr) \cdot g'(x).$$

证明思路：令 $\Delta u = g(x+\Delta x) - g(x)$，当 $g'(x) \neq 0$ 时，

$$\frac{\Delta h}{\Delta x} = \frac{f(u+\Delta u)-f(u)}{\Delta u} \cdot \frac{\Delta u}{\Delta x} \xrightarrow{\Delta x \to 0} f'(u)\cdot g'(x).$$

$g'(x) = 0$ 的情形需单独处理，结论不变。

实验单元（SymPy）

from sympy import symbols, diff, factor

x = symbols('x')
f = x**3 - 2*x

# 求导
df = diff(f, x)
print("f'(x) =", df)          # 3*x**2 - 2

# 链式法则示例：h(x) = sin(x^3)
from sympy import sin
h = sin(x**3)
print("h'(x) =", diff(h, x))  # 3*x**2*cos(x**3)

# 在 x=1 处求值
print("f'(1) =", df.subs(x, 1))  # 1

运行上述代码，可验证手算结果，并直观体验链式法则在复合函数求导中的应用。
