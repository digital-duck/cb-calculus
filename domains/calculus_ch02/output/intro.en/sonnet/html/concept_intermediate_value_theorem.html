Intermediate Value Theorem

Definition. Let $f : [a, b] \to \mathbb{R}$ be a continuous function on the closed interval $[a, b]$. If $N$ is any real number strictly between $f(a)$ and $f(b)$ — that is, $\min(f(a), f(b)) < N < \max(f(a), f(b))$ — then there exists at least one point $c \in (a, b)$ such that $f(c) = N$.

Informally, a continuous function cannot jump from one value to another without passing through every intermediate value. The graph of $f$ must cross every horizontal line $y = N$ that lies between $y = f(a)$ and $y = f(b)$.

Worked Example. Show that $f(x) = x^3 - x - 1$ has a root in the interval $[1, 2]$.

Evaluate at the endpoints:

$$f(1) = 1 - 1 - 1 = -1 < 0, \qquad f(2) = 8 - 2 - 1 = 5 > 0.$$

Since $f$ is a polynomial (hence continuous everywhere), and $0$ lies strictly between $f(1) = -1$ and $f(2) = 5$, the Intermediate Value Theorem guarantees a $c \in (1, 2)$ with $f(c) = 0$. Numerical methods refine this to $c \approx 1.3247$.

Key Theorem (Proof Sketch). The result follows from the completeness of $\mathbb{R}$. Without loss of generality assume $f(a) < N < f(b)$. Define $S = \{x \in [a,b] : f(x) \leq N\}$. This set is non-empty (it contains $a$) and bounded above by $b$, so by the least-upper-bound property $c = \sup S$ exists. Continuity of $f$ at $c$ forces $f(c) = N$: if $f(c) < N$ one can find points of $S$ larger than $c$, contradicting its definition as supremum; if $f(c) > N$ then $f > N$ on a neighbourhood of $c$, again a contradiction. $\square$

A direct consequence is the existence of $n$-th roots: for any $y \geq 0$ and integer $n \geq 1$, the function $g(x) = x^n$ is continuous with $g(0) = 0$ and $g(y+1) > y$, so there exists $c$ with $c^n = y$.

from sympy import symbols, solve, Rational
from sympy.plotting import plot

x = symbols('x')
f = x**3 - x - 1

# Confirm sign change
print(f.subs(x, 1), f.subs(x, 2))   # -1, 5

# Locate root numerically
root = solve(f, x)
print([r.evalf() for r in root])

plot(f, (x, 1, 2), title='f(x) = x³ − x − 1', xlabel='x', ylabel='f(x)')
