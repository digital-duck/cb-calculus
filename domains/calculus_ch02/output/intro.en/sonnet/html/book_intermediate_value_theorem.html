Concept Book: Intermediate Value Theorem

Calculus Ch02 · Generated by SPL

Payoff

The Intermediate Value Theorem is the first result in analysis that transforms a qualitative observation — a continuous function cannot jump — into a rigorous existence guarantee. Every concept developed in the preceding chapters has been, in retrospect, preparation for this moment: limits gave us a language for proximity, continuity gave us a class of functions that respect that language, and the completeness of the real line furnished the ground on which the theorem stands.

Theorem (Intermediate Value Theorem). Let $f : [a, b] \to \mathbb{R}$ be continuous. If $k$ is any value strictly between $f(a)$ and $f(b)$ — that is, $f(a) < k < f(b)$ or $f(b) < k < f(a)$ — then there exists at least one $c \in (a, b)$ such that $f(c) = k$.

The proof distills to a single idea: the set $S = \{x \in [a,b] : f(x) \le k\}$ is non-empty and bounded above, so its supremum $c = \sup S$ exists by completeness. Continuity of $f$ then forces $f(c) = k$; neither $f(c) < k$ nor $f(c) > k$ can survive contact with the definition of supremum without contradiction.

Worked Example. Show that $p(x) = x^3 - x - 1$ has a root in $(1, 2)$.

Observe $p(1) = -1 < 0$ and $p(2) = 5 > 0$. Since $p$ is a polynomial — hence continuous on all of $\mathbb{R}$ — the IVT applies on $[1, 2]$ with $k = 0$. There exists $c \in (1, 2)$ with $p(c) = 0$. No explicit formula for $c$ is needed; existence is already secured.

This pattern — sign change implies root — is precisely the engine driving root-finding algorithms such as the bisection method, where the interval $[a,b]$ is halved at each step. IVT certifies that the process is chasing something real.

More broadly, any time a physical or computational model requires that some output must pass through a target value as parameters vary continuously, the IVT is the silent guarantor. Equilibrium prices in economics, fixed-point iterations in numerical analysis, and zero-crossings in signal processing all rely, at their foundations, on this single theorem.
