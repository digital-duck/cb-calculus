Exponential Decay Model

定义

指数衰减模型描述一个量随时间以与其当前值成正比的速率减少的过程。设 $N(t)$ 为时刻 $t$ 时的量，则其变化率满足微分方程

$$\frac{dN}{dt} = -\lambda N(t), \quad \lambda > 0,$$

其中 $\lambda$ 称为衰减常数（decay constant），单位为时间的倒数。给定初始条件 $N(0) = N_0$，方程的唯一解为

$$N(t) = N_0 e^{-\lambda t}.$$

当 $t \to \infty$ 时，$N(t) \to 0$，体现出量的持续减少。另一常用参数为半衰期 $t_{1/2}$，定义为量减少至初始值一半所需的时间，满足

$$N_0 e^{-\lambda t_{1/2}} = \frac{N_0}{2} \implies t_{1/2} = \frac{\ln 2}{\lambda}.$$

具体例题

碳-14（$^{14}\mathrm{C}$）的半衰期为 $t_{1/2} = 5730$ 年。考古学家测得某木炭样本中碳-14 的含量为初始值的 $25\%$，估算该样本的年龄。

由 $N(t) = N_0 e^{-\lambda t}$ 及条件 $N(t) = 0.25 N_0$，得

$$0.25 = e^{-\lambda t} \implies t = \frac{\ln 4}{\lambda} = \frac{2\ln 2}{\lambda} = 2 \cdot t_{1/2} = 2 \times 5730 = 11460 \text{ 年}.$$

因此，该样本距今约 $11460$ 年。

关键定理

唯一性定理：满足 $\dfrac{dN}{dt} = -\lambda N$（$\lambda > 0$）及初始条件 $N(0) = N_0$ 的连续可微函数唯一，为 $N(t) = N_0 e^{-\lambda t}$。

证明思路：将方程改写为 $\dfrac{dN}{N} = -\lambda\, dt$，两边积分得 $\ln N = -\lambda t + C$，由初始条件定出 $C = \ln N_0$，从而 $N(t) = N_0 e^{-\lambda t}$。唯一性由 Picard–Lindelöf 定理保证，因右端函数关于 $N$ 满足 Lipschitz 条件。$\blacksquare$

实验单元（SymPy）

import sympy as sp

t, lam, N0 = sp.symbols('t lambda N_0', positive=True)

# 定义解析解
N = N0 * sp.exp(-lam * t)

# 验证满足微分方程
ode_check = sp.diff(N, t) + lam * N
print("ODE 验证（应为 0）：", sp.simplify(ode_check))

# 计算半衰期
t_half = sp.solve(N - N0 / 2, t)[0]
print("半衰期 t_(1/2) =", t_half)

# 碳-14 数值示例：lambda = ln2/5730
lam_val = sp.ln(2) / 5730
age = sp.solve(N0 * sp.exp(-lam_val * t) - 0.25 * N0, t)[0]
print("样本年龄（年）：", sp.simplify(age))
