Natural Logarithm Integral Def

定义（自然对数的积分定义）

对任意实数 $x > 0$，自然对数函数定义为

$$\ln x = \int_1^x \frac{1}{t}\, dt.$$

此处积分表示以 $t$ 轴为基准、曲线 $y = \tfrac{1}{t}$ 与区间 $[1, x]$（或 $[x, 1]$，当 $x < 1$ 时取负值）所围成的有向面积。这一定义完全绕开了指数函数，从纯分析角度出发建立对数的理论基础。

具体例子

计算 $\ln 2$ 的近似值。令 $f(t) = \tfrac{1}{t}$，对区间 $[1, 2]$ 使用梯形法则，取两个子区间 $[1, 1.5]$ 与 $[1.5, 2]$，步长 $h = 0.5$：

$$\ln 2 \approx \frac{0.5}{2}\!\left(f(1) + 2f(1.5) + f(2)\right) = \frac{0.5}{2}\!\left(1 + \frac{4}{3} + \frac{1}{2}\right) = \frac{0.5}{2} \cdot \frac{17}{6} \approx 0.708.$$

精确值为 $\ln 2 \approx 0.6931$，误差约 $2.2\%$，加密分割后可系统地降低误差。

核心定理

定理（微积分基本定理的推论）：设 $F(x) = \int_1^x \tfrac{1}{t}\,dt$，则

  • $F'(x) = \dfrac{1}{x}$，对所有 $x > 0$ 成立；
  • $F(1) = 0$；
  • 对任意 $a, b > 0$，有 $F(ab) = F(a) + F(b)$。

    • 证明要点：性质 1 直接由微积分基本定理得出。性质 3 令 $G(b) = F(ab) - F(a) - F(b)$，对 $b$ 求导得 $G'(b) = \tfrac{a}{ab} - \tfrac{1}{b} = 0$，故 $G$ 为常数；令 $b = 1$ 得 $G(1) = F(a) - F(a) - 0 = 0$，从而 $G \equiv 0$。$\blacksquare$

    性质 3 正是对数法则 $\ln(ab) = \ln a + \ln b$ 的严格来源。

    实验单元（SymPy）

    from sympy import *
t, x = symbols('t x', positive=True)

ln_def = Integral(1/t, (t, 1, x))
print("ln(x) 积分定义：", ln_def)
print("化简结果：      ", simplify(ln_def.doit()))

# 验证加法法则
a, b = symbols('a b', positive=True)
lhs = integrate(1/t, (t, 1, a*b))
rhs = integrate(1/t, (t, 1, a)) + integrate(1/t, (t, 1, b))
print("ln(ab) = ln(a)+ln(b)：", simplify(lhs - rhs) == 0)

    运行上述代码，simplify(lhs - rhs) 应输出 0，从符号计算层面验证了性质 3。
