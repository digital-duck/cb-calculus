Hyperbolic Functions

定义

双曲函数是以自然指数函数为基础构造的一族基本函数，其定义如下：

$$\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}$$

由此派生出：

$$\tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

以及倒数形式 $\operatorname{csch} x$、$\operatorname{sech} x$、$\coth x$，定义方式与三角函数的倒数类比。双曲函数的命名源于其与单位双曲线 $x^2 - y^2 = 1$ 的参数关系：点 $(\cosh t,\, \sinh t)$ 恒满足该方程，正如 $(\cos t,\, \sin t)$ 满足单位圆方程。

例题

计算 $\cosh(\ln 3)$ 的值。

将 $x = \ln 3$ 代入定义：

$$\cosh(\ln 3) = \frac{e^{\ln 3} + e^{-\ln 3}}{2} = \frac{3 + \tfrac{1}{3}}{2} = \frac{\tfrac{10}{3}}{2} = \frac{5}{3}$$

此结果亦可验证恒等式：$\cosh^2(\ln 3) - \sinh^2(\ln 3) = 1$。

基本恒等式与定理

定理（基本双曲恒等式）： 对一切实数 $x$，有

$$\cosh^2 x - \sinh^2 x = 1$$

证明思路： 直接展开：

$$\cosh^2 x - \sinh^2 x = \left(\frac{e^x+e^{-x}}{2}\right)^2 - \left(\frac{e^x-e^{-x}}{2}\right)^2 = \frac{(e^{2x}+2+e^{-2x})-(e^{2x}-2+e^{-2x})}{4} = \frac{4}{4} = 1 \qquad \square$$

此外，导数关系与三角函数高度类比：

$$\frac{d}{dx}\sinh x = \cosh x, \qquad \frac{d}{dx}\cosh x = \sinh x$$

注意后者符号与三角函数不同（无负号）。

实验单元（SymPy）

from sympy import *
x = symbols('x')

# 验证基本恒等式
expr = cosh(x)**2 - sinh(x)**2
print(simplify(expr))          # 输出：1

# 计算具体值
print(cosh(log(3)))            # 输出：5/3

# 求导
print(diff(sinh(x), x))        # 输出：cosh(x)
print(diff(cosh(x), x))        # 输出：sinh(x)

运行上述代码，可直观验证恒等式及导数公式，加深对双曲函数代数结构的理解。
