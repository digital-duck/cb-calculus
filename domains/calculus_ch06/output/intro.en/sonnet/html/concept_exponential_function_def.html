Exponential Function Def

Definition. Let $b > 0$ with $b \neq 1$. The exponential function with base $b$ is the function $f : \mathbb{R} \to (0, \infty)$ defined by

$$f(x) = b^x.$$

More precisely, for rational $x = p/q$ we set $b^x = \sqrt[q]{b^p}$, and we extend to all real $x$ by continuity: $b^x = \lim_{r \to x} b^r$ where the limit is taken over rationals $r$. The natural exponential function corresponds to the base $b = e \approx 2.71828$, where $e$ is Euler's number, and is written $\exp(x) = e^x$.

Worked Example. Evaluate and compare $2^{3/2}$ and $e^1$.

For $2^{3/2}$, write $2^{3/2} = (2^3)^{1/2} = 8^{1/2} = 2\sqrt{2} \approx 2.828$. For $e^1 = e \approx 2.718$. Thus $e^1 < 2^{3/2}$, illustrating that the ordering of exponential values depends on both the base and the exponent.

Key Theorem (Fundamental Properties of Exponentials). Let $b > 0$, $b \neq 1$, and let $x, y \in \mathbb{R}$. Then:

  • $b^{x+y} = b^x \cdot b^y$
  • $b^{x-y} = b^x / b^y$
  • $(b^x)^y = b^{xy}$
  • $\dfrac{d}{dx} e^x = e^x$

    • Proof sketch of (4). Using the limit definition of the derivative,

    $$\frac{d}{dx} e^x = \lim_{h \to 0} \frac{e^{x+h} - e^x}{h} = e^x \lim_{h \to 0} \frac{e^h - 1}{h}.$$

    One shows via the Taylor series $e^h = 1 + h + h^2/2! + \cdots$ that the remaining limit equals $1$, giving $\tfrac{d}{dx} e^x = e^x$. This self-replicating derivative is the defining characteristic of the natural exponential. $\square$

    from sympy import symbols, exp, E, sqrt, simplify, diff
