Growth Rates

Definition. Let $f$ and $g$ be positive-valued functions defined on $[a, \infty)$. We say $f$ grows no faster than $g$, written $f(x) = O(g(x))$ as $x \to \infty$, if there exist constants $C > 0$ and $x_0 \geq a$ such that

$$f(x) \leq C \cdot g(x) \quad \text{for all } x \geq x_0.$$

If additionally $g(x) = O(f(x))$, the two functions are asymptotically equivalent in order, written $f(x) = \Theta(g(x))$. The standard growth hierarchy, from slowest to fastest, is

$$1 \;\prec\; \log x \;\prec\; x^\alpha \;\prec\; x^\beta \;\prec\; a^x \;\prec\; x! \;\prec\; x^x$$

for any fixed $0 < \alpha < \beta$ and $a > 1$.

Worked Example. Compare $f(x) = 3x^2 + 5x$ and $g(x) = x^2$.

For $x \geq 1$ we have $5x \leq 5x^2$, so

$$f(x) = 3x^2 + 5x \leq 8x^2 = 8\, g(x).$$

Hence $f(x) = O(x^2)$. In the other direction, $f(x) \geq 3x^2 = 3\, g(x)$ for all $x > 0$, so $g(x) = O(f(x))$ as well. Therefore $f(x) = \Theta(x^2)$: the linear term is dominated by the quadratic and does not affect the asymptotic order.

Key Theorem (L'Hôpital Growth Comparison). Suppose $f$ and $g$ are differentiable, $g(x) \to \infty$, and

$$L = \lim_{x \to \infty} \frac{f(x)}{g(x)}$$

exists (finitely or as $+\infty$). Then:

  • $L = 0 \implies f(x) = o(g(x))$ (strictly slower growth),
  • $0 < L < \infty \implies f(x) = \Theta(g(x))$,
  • $L = +\infty \implies g(x) = o(f(x))$.

    • Proof sketch. Apply L'Hôpital's rule or the squeeze theorem to bound the ratio within $[\,L - \varepsilon,\, L + \varepsilon\,]$ for sufficiently large $x$, then read off the $O$-constants directly from the bounding constants. $\square$

    Lab Cell (SymPy).

    from sympy import symbols, limit, oo, log, exp, factorial

x = symbols('x', positive=True)

pairs = [
    (log(x),    x),
    (x**2,      exp(x)),
    (3*x**2 + 5*x, x**2),
]

for f, g in pairs:
    L = limit(f / g, x, oo)
    print(f"lim ({f}) / ({g})  =  {L}")

    Running this cell confirms the hierarchy: $\log x / x \to 0$, $x^2 / e^x \to 0$, and $(3x^2+5x)/x^2 \to 3$, validating both the strict dominance cases and the $\Theta$ relationship demonstrated above.
