First Derivative Test

Definition. Let $f$ be a function continuous on an open interval $I$ containing a critical point $c$, where $f'(c) = 0$ or $f'(c)$ does not exist. The First Derivative Test classifies $c$ as follows:

  • If $f'(x) > 0$ for $x < c$ and $f'(x) < 0$ for $x > c$ (in a punctured neighbourhood of $c$), then $f(c)$ is a local maximum.
  • If $f'(x) < 0$ for $x < c$ and $f'(x) > 0$ for $x > c$, then $f(c)$ is a local minimum.
  • If $f'$ does not change sign at $c$, then $f(c)$ is neither a local extremum.

    • Geometrically, a sign change from positive to negative indicates the function rises then falls — a peak — while the reverse pattern indicates a valley.

    Worked Example. Consider $f(x) = x^3 - 3x + 2$. Differentiating gives $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$, so the critical points are $x = -1$ and $x = 1$.

    Construct a sign chart for $f'$:

    | Interval | $(−\infty,\,-1)$ | $(−1,\,1)$ | $(1,\,\infty)$ | |---|---|---|---| | Sign of $f'$ | $+$ | $-$ | $+$ |

    At $x = -1$: sign changes from $+$ to $-$, so $f(-1) = 4$ is a local maximum. At $x = 1$: sign changes from $-$ to $+$, so $f(1) = 0$ is a local minimum.

    Theorem (First Derivative Test). Let $f$ be continuous on $(a,b)$ and differentiable on $(a,b) \setminus \{c\}$, where $c \in (a,b)$ is a critical point. If there exists $\delta > 0$ such that $f'$ has constant sign on $(c-\delta,c)$ and the opposite sign on $(c,c+\delta)$, then $f(c)$ is a strict local extremum.

    Proof sketch. By the Mean Value Theorem, on any subinterval of $(c-\delta, c)$ where $f' > 0$, the function is strictly increasing; hence $f(x) < f(c)$ for all $x \in (c-\delta, c)$. The decreasing condition on $(c, c+\delta)$ yields the same inequality on the right. Together these give $f(c) > f(x)$ in a punctured neighbourhood, confirming a local maximum. The minimum case is symmetric. $\blacksquare$

    from sympy import symbols, diff, solve, factor

x = symbols('x')
f = x**3 - 3*x + 2
fp = diff(f, x)
critical_pts = solve(fp, x)

for c in critical_pts:
    left  = fp.subs(x, c - 0.01)
    right = fp.subs(x, c + 0.01)
    nature = ("local max" if left > 0 and right < 0
              else "local min" if left < 0 and right > 0
              else "neither")
    print(f"x = {c}: f'  changes sign {float(left):+.3f} → {float(right):+.3f}  → {nature}")
