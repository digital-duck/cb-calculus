Critical Point

Definition. Let $f : D \subseteq \mathbb{R} \to \mathbb{R}$ be a differentiable function on an open interval $D$. A point $c \in D$ is called a critical point of $f$ if

$$f'(c) = 0.$$

More generally, if $f$ is only defined on a closed interval $[a, b]$, the endpoints $a$ and $b$ are also considered critical points in the search for extrema, even when $f'$ exists there. The value $f(c)$ is called the critical value corresponding to $c$. Critical points are candidates for local maxima, local minima, or saddle points (inflection points with zero slope); the first and second derivative tests distinguish among these cases.

Worked Example. Consider $f(x) = x^3 - 3x + 1$ on $\mathbb{R}$. To locate the critical points, compute

$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1).$$

Setting $f'(x) = 0$ yields $x = 1$ and $x = -1$. Evaluating: $f(-1) = (-1)^3 - 3(-1) + 1 = 3$ and $f(1) = 1 - 3 + 1 = -1$. The second derivative is $f''(x) = 6x$. Since $f''(-1) = -6 < 0$, the point $x = -1$ is a local maximum; since $f''(1) = 6 > 0$, the point $x = 1$ is a local minimum.

Key Theorem (Fermat's Theorem). If $f$ is differentiable on an open interval and $f$ attains a local extremum at $c$, then $f'(c) = 0$.

Proof sketch. Suppose $f$ has a local maximum at $c$. For small $h > 0$, the difference quotient satisfies

$$\frac{f(c+h)-f(c)}{h} \leq 0 \quad \text{and} \quad \frac{f(c-h)-f(c)}{-h} \geq 0.$$

Taking $h \to 0^+$ and $h \to 0^-$ respectively forces $f'(c) \leq 0$ and $f'(c) \geq 0$, hence $f'(c) = 0$. The local minimum case is analogous. $\blacksquare$

Note that the converse fails: $f(x) = x^3$ satisfies $f'(0) = 0$, yet $x = 0$ is neither a maximum nor a minimum.

Lab Cell.

import sympy as sp

x = sp.Symbol('x')
f = x**3 - 3*x + 1

f_prime = sp.diff(f, x)
critical_pts = sp.solve(f_prime, x)

for c in critical_pts:
    f2 = sp.diff(f_prime, x).subs(x, c)
    nature = "local max" if f2 < 0 else "local min" if f2 > 0 else "inconclusive"
    print(f"x = {c}, f(x) = {f.subs(x, c)}, f''(x) = {f2} → {nature}")
