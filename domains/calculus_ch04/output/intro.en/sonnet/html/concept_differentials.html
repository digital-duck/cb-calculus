Differentials

Definition. Let $f$ be a differentiable function of $x$. The differential of $x$, written $dx$, is an independent variable representing an arbitrary increment in $x$. The differential of $f$, written $df$ or $dy$, is defined by

$$df = f'(x)\,dx.$$

Unlike the derivative $f'(x) = dy/dx$, which is a limit of a ratio, $df$ and $dx$ are genuine quantities — infinitesimal proxies for the actual change $\Delta y = f(x + \Delta x) - f(x)$ and the step $\Delta x$. When $\Delta x$ is small, $df \approx \Delta y$, with the error being $O((\Delta x)^2)$.

Worked Example. Estimate $\sqrt{4.06}$ using differentials.

Set $f(x) = \sqrt{x}$, so $f'(x) = \tfrac{1}{2}x^{-1/2}$. Choose the base point $x = 4$ (where $f$ is easy to evaluate exactly) and let $dx = 0.06$. Then

$$df = f'(4)\,dx = \frac{1}{2\sqrt{4}}\cdot 0.06 = \frac{1}{4}\cdot 0.06 = 0.015.$$

Therefore $\sqrt{4.06} \approx f(4) + df = 2 + 0.015 = 2.015$. The true value is $\approx 2.01494$, so the error is less than $0.00006$ — demonstrating the quality of the linear approximation for small $dx$.

Key Theorem (Linear Approximation via Differentials). If $f$ is differentiable at $a$ and $\Delta x = dx$ is small, then

$$\Delta y \;=\; f'(a)\,dx \;+\; \epsilon\,dx, \qquad \text{where } \epsilon \to 0 \text{ as } dx \to 0.$$

Proof sketch. By the definition of the derivative, $f'(a) = \lim_{\Delta x \to 0} \Delta y/\Delta x$. Writing $\Delta y/\Delta x = f'(a) + \epsilon$ with $\epsilon \to 0$ and multiplying through by $\Delta x$ gives the result. $\square$

The differential $df = f'(a)\,dx$ is thus the principal linear part of $\Delta y$; it captures the dominant behavior while the $\epsilon\,dx$ remainder vanishes faster than $dx$.

Lab Cell (SymPy).

import sympy as sp

x = sp.Symbol('x')
f = sp.sqrt(x)
dx = sp.Symbol('dx')

df = sp.diff(f, x) * dx
base = 4

approx = f.subs(x, base) + df.subs(x, base).subs(dx, sp.Rational(6, 100))
print("Differential approximation:", approx)          # 2 + 3/200
print("Exact value:", float(sp.sqrt(sp.Rational(406, 100))))

Running this cell confirms the approximation $2 + \tfrac{3}{200} = 2.015$ and invites experimentation with different base points and step sizes.
