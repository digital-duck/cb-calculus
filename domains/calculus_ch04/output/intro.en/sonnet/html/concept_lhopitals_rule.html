L'Hôpital's Rule

Definition. Let $f$ and $g$ be functions that are differentiable on an open interval $I$ containing $a$ (except possibly at $a$ itself), with $g'(x) \neq 0$ on $I \setminus \{a\}$. If the limit $\lim_{x \to a} f(x)/g(x)$ produces an indeterminate form of type $0/0$ or $\pm\infty/\pm\infty$, then

$$\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)},$$

provided the right-hand limit exists (or equals $\pm\infty$). The rule applies equally to one-sided limits and to limits as $x \to \pm\infty$.

Worked Example. Evaluate $\displaystyle\lim_{x \to 0} \frac{\sin x}{x}$.

Direct substitution gives $\sin 0 / 0 = 0/0$, an indeterminate form. Differentiating numerator and denominator separately:

$$\lim_{x \to 0} \frac{\sin x}{x} = \lim_{x \to 0} \frac{\cos x}{1} = \cos 0 = 1.$$

As a second illustration, consider $\displaystyle\lim_{x \to \infty} \frac{e^x}{x^2}$, which has the form $\infty/\infty$. Applying the rule twice:

$$\lim_{x \to \infty} \frac{e^x}{x^2} = \lim_{x \to \infty} \frac{e^x}{2x} = \lim_{x \to \infty} \frac{e^x}{2} = \infty.$$

This confirms that exponential growth dominates any polynomial.

Key Theorem (Cauchy's Mean Value Theorem). The rigorous foundation for L'Hôpital's Rule is the Cauchy Mean Value Theorem: if $f$ and $g$ are continuous on $[a, b]$ and differentiable on $(a, b)$, there exists $c \in (a, b)$ such that

$$[f(b) - f(a)]\, g'(c) = [g(b) - g(a)]\, f'(c).$$

By applying this theorem to the interval $[a, a+h]$ as $h \to 0$, one can show that the ratio $f(x)/g(x)$ converges to the same limit as $f'(x)/g'(x)$ whenever the hypotheses of L'Hôpital's Rule are satisfied. A complete proof requires careful treatment of the $\infty/\infty$ case using nested applications of the theorem.

Lab Cell.

from sympy import symbols, sin, exp, limit, oo, diff

x = symbols('x')

# 0/0 form
expr1 = sin(x) / x
print(limit(expr1, x, 0))          # 1

# inf/inf form
expr2 = exp(x) / x**2
print(limit(expr2, x, oo))         # oo

# Verify by differentiating numerator and denominator manually
f, g = sin(x), x
print(limit(diff(f)/diff(g), x, 0))  # 1
