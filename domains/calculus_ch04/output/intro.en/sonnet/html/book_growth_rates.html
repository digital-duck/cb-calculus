Concept Book: Growth Rates

Calculus Ch04 · Generated by SPL

Payoff

Every thread developed in this textbook — limits, derivatives, series expansions, asymptotic notation — converges at a single idea: the precise characterisation of how fast a quantity grows. Growth rates provide the language in which calculus answers its most consequential questions, transforming qualitative intuitions ("this grows faster than that") into quantitative, provable statements.

Definition. Let $f, g : \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ be eventually positive functions. We say $f$ grows at the same rate as $g$, written $f \asymp g$, if there exist constants $0 < c_1 \le c_2 < \infty$ and $x_0 > 0$ such that

$$c_1 \, g(x) \;\le\; f(x) \;\le\; c_2 \, g(x) \qquad \text{for all } x > x_0.$$

The finer distinctions — $f = o(g)$, $f = O(g)$, $f \sim g$ — stratify this ordering into a total hierarchy on equivalence classes of growth.

Worked example. Compare $f(x) = x^2 + 3x$ and $g(x) = x^2$. Dividing,

$$\frac{f(x)}{g(x)} = 1 + \frac{3}{x} \;\xrightarrow{x \to \infty}\; 1,$$

so $f \sim g$: the linear term is asymptotically negligible. Algorithmically, an $O(x^2 + 3x)$ procedure and an $O(x^2)$ procedure belong to the same complexity class; the constant factor matters in practice but not in classification.

Key theorem (Comparison test for improper integrals). If $0 \le f(x) \le C g(x)$ for all $x \ge a$, then $\int_a^\infty g(x)\,dx < \infty$ implies $\int_a^\infty f(x)\,dx < \infty$. This is growth-rate theory applied to integrability: controlling asymptotic size controls convergence.

Lab cell.

from sympy import *
x = symbols('x', positive=True)
f, g = x**2 + 3*x, x**2
print(limit(f / g, x, oo))          # 1  → f ~ g
print(limit(log(f) / log(g), x, oo)) # 1  → same logarithmic order

Growth rates are the natural endpoint of this book because they unify every analytic tool studied here under one comparative framework: derivatives measure instantaneous rates; series reveal coefficient decay; asymptotic notation ranks the resulting scales globally. The concept does not close a door — it opens an entire corridor. Each application domain (algorithm analysis, population dynamics, signal processing, financial modelling) is simply a specialised dialect of the same underlying grammar.

Pick one domain and follow it. The next chapter invites you to enter the world of algorithm complexity, where growth-rate classifications determine whether a computation is feasible for a million inputs or only for ten.
