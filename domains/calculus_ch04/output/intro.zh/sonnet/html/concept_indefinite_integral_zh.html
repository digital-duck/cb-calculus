不定积分

定义。 设函数 $f(x)$ 在区间 $I$ 上有定义。若存在函数 $F(x)$，使得对所有 $x \in I$ 均有

$$F'(x) = f(x),$$

则称 $F(x)$ 为 $f(x)$ 在 $I$ 上的一个原函数。$f(x)$ 的全体原函数构成的集合称为 $f(x)$ 的不定积分，记作

$$\int f(x)\,dx = F(x) + C,$$

其中 $C \in \mathbb{R}$ 为任意常数，称为积分常数。符号 $\int$ 称为积分号，$f(x)$ 称为被积函数，$x$ 称为积分变量。

由于任意两个原函数之差为常数，不定积分所表示的并非单一函数，而是一族彼此相差常数的函数。

例题。 求 $\displaystyle\int 3x^2\,dx$。

解： 注意到 $\dfrac{d}{dx}(x^3) = 3x^2$，故 $x^3$ 是 $3x^2$ 的一个原函数。由定义，

$$\int 3x^2\,dx = x^3 + C.$$

验证：对 $x^3 + C$ 求导，得 $(x^3 + C)' = 3x^2$，与被积函数一致。$\blacksquare$

定理（不定积分的线性性质）。 设 $f(x)$ 与 $g(x)$ 均在区间 $I$ 上存在原函数，$\alpha, \beta \in \mathbb{R}$，则

$$\int [\alpha f(x) + \beta g(x)]\,dx = \alpha \int f(x)\,dx + \beta \int g(x)\,dx.$$

证明思路： 设 $F'(x) = f(x)$，$G'(x) = g(x)$。令 $H(x) = \alpha F(x) + \beta G(x)$，则

$$H'(x) = \alpha F'(x) + \beta G'(x) = \alpha f(x) + \beta g(x),$$

故 $H(x)$ 是 $\alpha f(x) + \beta g(x)$ 的原函数，命题成立。$\square$

线性性质使复杂函数的积分可逐项分解处理，是后续计算的基础。

实验单元（SymPy）

from sympy import symbols, integrate, cos, exp

x = symbols('x')

# 多项式积分
print(integrate(3*x**2, x))          # x**3

# 三角函数积分
print(integrate(cos(x), x))          # sin(x)

# 指数函数积分
print(integrate(exp(x), x))          # exp(x)

# 线性组合
print(integrate(2*x + cos(x), x))    # x**2 + sin(x)

运行上述代码可验证：SymPy 返回的结果均省略常数 $C$，实际使用时应手动补充。
