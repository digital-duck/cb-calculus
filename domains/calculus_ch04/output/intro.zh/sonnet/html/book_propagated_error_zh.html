误差传播的本质意涵

贯穿本书的核心问题始终是：当我们对输入量的了解本就不完整时，由此导出的结论究竟可信到何种程度？传播误差（propagated error）正是对这一问题给出的定量答案。设物理量 $y = f(x_1, x_2, \ldots, x_n)$，各输入量的标准不确定度分别为 $\sigma_{x_i}$，则在各分量相互独立的假设下，输出量的合成不确定度由以下公式给出：

$$\sigma_y = \sqrt{\sum_{i=1}^{n} \left(\frac{\partial f}{\partial x_i}\right)^2 \sigma_{x_i}^2}$$

这一结果并非经验性的近似，而是以泰勒展开为基础的严格一阶线性化推导的直接推论。它将"不确定度如何流动"这一本质上属于几何学的问题，转化为可计算、可验证、可优化的代数问题。至此，误差不再是实验末尾的附注，而成为贯穿整个分析过程的结构性量。

一个具体的收益：单摆测量重力加速度

设单摆周期 $T = 2\pi\sqrt{L/g}$，从而 $g = 4\pi^2 L / T^2$。若摆长测量不确定度为 $\sigma_L$，周期测量不确定度为 $\sigma_T$，则重力加速度的传播误差为：

$$\frac{\sigma_g}{g} = \sqrt{\left(\frac{\sigma_L}{L}\right)^2 + \left(\frac{2\sigma_T}{T}\right)^2}$$

周期项前的系数 $2$ 揭示了一个实用结论：计时误差对最终结果的影响是摆长误差的两倍。这一信息直接指导实验设计——在精度有限的条件下，应优先提高计时精度。误差传播因此成为资源分配的决策工具，而非事后的说明文字。

核心定理：误差椭球与置信域

当输入误差服从多元正态分布时，输出量的不确定度在参数空间中定义了一个误差椭球。其半轴由 Hessian 矩阵的特征值决定，主方向对应最敏感的扰动模式。这一几何图像是不确定度量化（UQ）、贝叶斯推断与灵敏度分析的共同语言基础。

实验室：用 SymPy 自动推导传播误差

import sympy as sp

L, T, sL, sT = sp.symbols('L T sigma_L sigma_T', positive=True)
g = 4 * sp.pi**2 * L / T**2

sigma_g = sp.sqrt(
    (sp.diff(g, L) * sL)**2 +
    (sp.diff(g, T) * sT)**2
).simplify()

sp.pprint(sigma_g)

运行上述单元格，SymPy 将自动完成偏微分与合成，输出结果与手算完全吻合。将 $f$ 替换为任意可微函数，传播误差的推导即刻自动化——这正是符号计算赋予实验科学家的核心能力。

邀请：深入一个应用领域

误差传播的框架在每一个依赖测量的领域中都找到了自然的落脚点：在药物代谢动力学中，它约束剂量-响应模型的可信区间；在音乐声学中，它量化调律误差对和声纯度的影响；在计量学与标准传递中，它是溯源链条上每一级精度声明的法定依据。
