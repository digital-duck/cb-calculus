Locating Absolute Extrema

定义。 设函数 $f$ 在闭区间 $[a, b]$ 上连续。若存在 $c \in [a, b]$ 使得对所有 $x \in [a, b]$ 均有 $f(c) \ge f(x)$，则称 $f(c)$ 为 $f$ 在 $[a, b]$ 上的绝对最大值（全局最大值）；若对所有 $x \in [a, b]$ 均有 $f(c) \le f(x)$，则称 $f(c)$ 为绝对最小值（全局最小值）。两者统称为绝对极值。由魏尔斯特拉斯极值定理，闭区间上的连续函数必然同时取得绝对最大值与绝对最小值。

求解步骤。 绝对极值只能在以下三类点处取得：①区间端点 $a$ 与 $b$；②区间内部使 $f'(x) = 0$ 的驻点；③区间内部使 $f'(x)$ 不存在的奇异点。算法如下：

  • 求导数 $f'(x)$，解方程 $f'(x) = 0$ 及确定 $f'(x)$ 不存在之点，找出 $[a,b]$ 内的所有候选点。
  • 计算 $f$ 在所有候选点及两端点处的函数值。
  • 比较上述函数值，最大者为绝对最大值，最小者为绝对最小值。

    • 例题。 求 $f(x) = x^3 - 3x^2 + 1$ 在 $[-1, 3]$ 上的绝对极值。

    解： 求导得

    $$f'(x) = 3x^2 - 6x = 3x(x-2).$$

    令 $f'(x) = 0$，解得驻点 $x = 0$ 与 $x = 2$，均在 $[-1, 3]$ 内。计算各候选点处的函数值：

    | $x$ | $f(x)$ | |-----|--------| | $-1$ | $(-1)^3 - 3(-1)^2 + 1 = -3$ | | $0$ | $0 - 0 + 1 = 1$ | | $2$ | $8 - 12 + 1 = -3$ | | $3$ | $27 - 27 + 1 = 1$ |

    比较可知，$f$ 在 $x = 0$ 与 $x = 3$ 处取得绝对最大值 $1$，在 $x = -1$ 与 $x = 2$ 处取得绝对最小值 $-3$。

    关键定理（闭区间法）。 若 $f$ 在 $[a,b]$ 上连续，则

    $$\max_{[a,b]} f = \max\bigl\{f(a),\, f(b),\, f(c_1),\dots,f(c_k)\bigr\},$$

    其中 $c_1, \dots, c_k$ 为所有内部临界点。此结论将无界搜索问题化为有限点的比较问题。

    # 实验单元：用 SymPy 验证上述结果
from sympy import *

x = symbols('x')
f = x**3 - 3*x**2 + 1
a, b = -1, 3

crit = solve(diff(f, x), x)
candidates = [a, b] + [c for c in crit if a <= c <= b]
values = {c: f.subs(x, c) for c in candidates}
print("函数值表：", values)
print("绝对最大值：", max(values.values()))
print("绝对最小值：", min(values.values()))
