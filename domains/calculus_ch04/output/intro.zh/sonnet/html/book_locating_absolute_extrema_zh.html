收益：绝对极值定位的意义与应用

定义回顾与成就

经过前几章的铺垫，我们已掌握定位函数绝对极值的完整方法：在闭区间 $[a, b]$ 上，对连续函数 $f(x)$ 求驻点（令 $f'(x) = 0$），识别不可微点，再与端点 $f(a)$、$f(b)$ 逐一比较，最大者即为绝对最大值，最小者即为绝对最小值。这一流程之所以是本章的自然终点，在于它将极限、导数与连续性三条主线汇聚于一处，形成一个可操作、可验证的判别程序。闭区间最大值定理保证极值必然存在，费马定理指明内部候选点的位置，端点检验则封闭了所有可能的逃逸路径。至此，"函数在哪里最大或最小"不再是直觉问题，而成为严格的数学结论。

具体例证

设某工厂的日产量成本函数为

$$C(x) = 0.02x^3 - 3x^2 + 200x + 1000, \quad x \in [10, 80]$$

其中 $x$ 为日产量（单位：吨）。令 $C'(x) = 0.06x^2 - 6x + 200 = 0$，解得

$$x = \frac{6 \pm \sqrt{36 - 48}}{0.12}$$

判别式为负，故区间内无驻点，绝对最小值只能在端点取得：$C(10) = 3820$，$C(80) = 11240$。因此日产量为 10 吨时成本最低，这一结论直接指导生产决策。

核心定理（极值存在定理）

> 定理（魏尔斯特拉斯极值定理）：若 $f$ 在闭区间 $[a,b]$ 上连续，则 $f$ 在 $[a,b]$ 上必取到绝对最大值与绝对最小值。

定理的证明依赖实数的完备性：连续函数将紧致集映射为紧致集，故像集有界且上下确界均可达。这不仅是存在性保证，更赋予搜索算法以终止的理论依据。

实验室：SymPy 验证

from sympy import symbols, diff, solve, Rational

x = symbols('x')
C = Rational(2,100)*x**3 - 3*x**2 + 200*x + 1000
dC = diff(C, x)
interior = solve(dC, x)
candidates = [p for p in interior if 10 <= p <= 80] + [10, 80]
print({p: C.subs(x, p) for p in candidates})

延伸邀请

绝对极值定位是应用优化的理论基石。无论是最小化工程结构的材料用量、最大化经济模型中的利润函数，还是在物流网络中寻找最优配送路径，其核心步骤均归结为本章所描述的候选点枚举与比较。若你希望亲历这一方法的全部威力，不妨深入探索应用优化专题——在那里，每一个现实约束都将化为一条边界，而极值定位的算法将在其中精确地找到最优解。
