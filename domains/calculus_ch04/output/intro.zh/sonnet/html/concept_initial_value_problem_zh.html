Initial Value Problem

定义。 设 $F$ 为定义在某区域 $D \subseteq \mathbb{R}^2$ 上的函数，初值问题（Initial Value Problem，简称 IVP）是指求满足以下条件的函数 $y(x)$：

$$ \frac{dy}{dx} = F(x,\, y), \qquad y(x_0) = y_0, $$

其中 $(x_0, y_0) \in D$ 称为初始条件（initial condition）。与一般微分方程不同，初值问题要求解曲线必须过指定点 $(x_0, y_0)$，从而在满足存在性的前提下唯一确定解。

例题。 求解初值问题

$$ \frac{dy}{dx} = 2x, \qquad y(1) = 3. $$

解： 对方程两边关于 $x$ 积分，得

$$ y = \int 2x\, dx = x^2 + C, $$

其中 $C$ 为任意常数。代入初始条件 $y(1) = 3$：

$$ 3 = 1^2 + C \implies C = 2. $$

故唯一解为 $y(x) = x^2 + 2$。可验证：$y'(x) = 2x$ 且 $y(1) = 3$，满足题设。

关键定理（Picard–Lindelöf 定理）。 若 $F(x, y)$ 在以 $(x_0, y_0)$ 为中心的矩形区域上连续，且关于 $y$ 满足 Lipschitz 条件，即存在常数 $L > 0$ 使得

$$ |F(x, y_1) - F(x, y_2)| \leq L\,|y_1 - y_2|, $$

则初值问题在 $x_0$ 的某邻域内存在唯一连续可微解。该定理保证了物理模型（如质点运动、电路响应）由初始状态唯一决定未来演化这一直觉的严格数学基础。

实验单元（SymPy）。

import sympy as sp

x = sp.Symbol('x')
y = sp.Function('y')

ode = sp.Eq(y(x).diff(x), 2*x)
sol = sp.dsolve(ode, y(x), ics={y(1): 3})
print(sol)          # 输出: Eq(y(x), x**2 + 2)
sp.plot(sol.rhs, (x, 0, 3), title='初值问题的解')

运行上述代码，SymPy 将自动施加初始条件并化简积分常数，所得曲线图直观展示解在 $(1, 3)$ 处穿过的几何意义。
