Mvt Corollaries

定义

均值定理（Mean Value Theorem，简称 MVT）的推论是一组由 MVT 直接衍生的重要结论，它们将函数的导数行为与函数整体性质紧密相连。设 $f$ 在闭区间 $[a, b]$ 上连续，在开区间 $(a, b)$ 上可微，则 MVT 保证存在 $c \in (a, b)$ 使得

$$f'(c) = \frac{f(b) - f(a)}{b - a}.$$

由此出发，可得三条核心推论：

推论一（零导数定理）：若对所有 $x \in (a, b)$ 均有 $f'(x) = 0$，则 $f$ 在 $[a, b]$ 上为常数函数。

推论二（单调性判别）：若 $f'(x) > 0$（或 $< 0$）对所有 $x \in (a, b)$ 成立，则 $f$ 在该区间上严格递增（或严格递减）。

推论三（Lipschitz 估计）：若 $|f'(x)| \leq M$ 对所有 $x \in (a, b)$ 成立，则对任意 $x_1, x_2 \in [a, b]$，有

$$|f(x_1) - f(x_2)| \leq M|x_1 - x_2|.$$

典型例题

设 $f(x) = x^3 - 3x$，在区间 $[0, 2]$ 上验证推论二。

计算导数：$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$。

在 $(1, 2)$ 上，$x > 1$ 且 $x > -1$，故 $f'(x) > 0$，由推论二知 $f$ 在 $[1, 2]$ 上严格递增。验证：$f(1) = -2$，$f(2) = 2$，确实 $f(2) > f(1)$，结论吻合。

关键定理

定理（函数相差常数）：设 $f, g$ 在 $(a, b)$ 上可微，且对所有 $x \in (a, b)$ 均有 $f'(x) = g'(x)$，则存在常数 $C$ 使得

$$f(x) = g(x) + C, \quad \forall x \in [a, b].$$

证明思路：令 $h = f - g$，则 $h'(x) = 0$，由推论一知 $h$ 为常数，从而结论成立。$\blacksquare$

此定理是不定积分唯一性（相差任意常数）的理论基础。

实验单元（SymPy）

from sympy import symbols, diff, solve, Rational

x = symbols('x')
f = x**3 - 3*x
a, b = 0, 2

# 求满足 MVT 的点 c
slope = (f.subs(x, b) - f.subs(x, a)) / (b - a)
c_vals = solve(diff(f, x) - slope, x)
print("MVT 点 c =", [v for v in c_vals if 0 < v < 2])

# 验证推论三的 Lipschitz 常数
M = max(abs(diff(f, x).subs(x, v)) for v in [0, 1, 2])
print("Lipschitz 常数上界 M =", M)
