First Derivative Test

定义。 设函数 $f$ 在点 $c$ 的某个开区间上可微，且 $f'(c) = 0$（或 $f'(c)$ 不存在但 $f$ 连续）。一阶导数判别法通过考察 $f'$ 在 $c$ 两侧的符号来判断 $f(c)$ 的极值类型：

  • 若 $f'$ 在 $c$ 左侧为正、右侧为负，则 $f(c)$ 是极大值；
  • 若 $f'$ 在 $c$ 左侧为负、右侧为正，则 $f(c)$ 是极小值；
  • 若 $f'$ 在 $c$ 两侧同号，则 $f(c)$ 不是极值（称为驻点但无极值）。

    • 直观上，导数的符号描述函数的单调方向：正值对应递增，负值对应递减。极大值恰好出现在函数从递增转为递减的时刻，极小值则相反。

    例题。 设 $f(x) = x^3 - 3x + 2$，求其极值点。

    解： 先求导并令其为零：

    $$f'(x) = 3x^2 - 3 = 3(x-1)(x+1) = 0 \implies x = \pm 1.$$

    对 $x = -1$：取 $x = -2$ 时 $f'(-2) = 9 > 0$，取 $x = 0$ 时 $f'(0) = -3 < 0$。符号由正变负，故 $f(-1) = 4$ 为极大值。

    对 $x = 1$：取 $x = 0$ 时 $f'(0) = -3 < 0$，取 $x = 2$ 时 $f'(2) = 9 > 0$。符号由负变正，故 $f(1) = 0$ 为极小值。

    关键定理。 设 $f$ 在包含 $c$ 的开区间 $I$ 上连续，$c$ 为 $f$ 的临界点。若存在 $\delta > 0$ 使得：

    $$\text{对所有 } x \in (c-\delta,\, c),\quad f'(x) > 0;\quad \text{对所有 } x \in (c,\, c+\delta),\quad f'(x) < 0,$$

    则 $f(c)$ 为严格极大值。极小值情形类似，方向互换。证明思路： 利用均值定理——对任意 $x \in (c-\delta, c)$，存在 $\xi \in (x, c)$ 使 $f(c) - f(x) = f'(\xi)(c - x) > 0$，故 $f(c) > f(x)$；右侧同理。

    实验单元（SymPy）。

    from sympy import symbols, diff, solve, simplify

x = symbols('x')
f = x**3 - 3*x + 2
fp = diff(f, x)

critical = solve(fp, x)
for c in critical:
    left  = fp.subs(x, c - 0.01)
    right = fp.subs(x, c + 0.01)
    kind  = "极大值" if left > 0 and right < 0 else "极小值" if left < 0 and right > 0 else "非极值"
    print(f"x = {c}: f(c) = {f.subs(x, c)},  类型 = {kind}")

    运行上述代码，学生可验证 $x = -1$ 给出极大值 $4$，$x = 1$ 给出极小值 $0$，与手算结果完全一致。
