初值问题的本质意义

经过本书前各章节的铺垫——从极限与导数的严格定义，到微分方程的一般理论——我们终于抵达核心：初值问题（Initial Value Problem，IVP）。所谓初值问题，是指在给定常微分方程

$$\frac{dy}{dx} = f(x, y), \quad y(x_0) = y_0$$

的条件下，求满足该方程且在 $x = x_0$ 处取值 $y_0$ 的唯一解 $y(x)$。Picard–Lindelöf 定理保证：若 $f$ 在 $(x_0, y_0)$ 的某邻域内连续且关于 $y$ 满足 Lipschitz 条件，则局部唯一解必然存在。这一结论是分析学与应用数学的交汇点：存在性回答"解是否存在"，唯一性回答"给定初始状态能否唯一预测未来"。

具体例子

考虑放射性衰变模型：

$$\frac{dN}{dt} = -\lambda N, \quad N(0) = N_0$$

其中 $\lambda > 0$ 为衰变常数，$N_0$ 为初始粒子数。分离变量并积分，得

$$N(t) = N_0 e^{-\lambda t}$$

该解完全由初始条件 $N(0) = N_0$ 唯一确定——改变 $N_0$ 则整条轨迹随之平移，充分体现了初值的决定性作用。

核心定理

Picard–Lindelöf 定理（简述）： 设 $f: D \to \mathbb{R}$ 在闭矩形 $D = [x_0 - a,\, x_0 + a] \times [y_0 - b,\, y_0 + b]$ 上连续，且存在常数 $L > 0$ 使得对所有 $(x, y_1), (x, y_2) \in D$ 均有

$$|f(x, y_1) - f(x, y_2)| \leq L|y_1 - y_2|$$

则 IVP 在 $|x - x_0| \leq \min\!\left(a,\, \frac{b}{M}\right)$（$M = \max_D |f|$）上存在唯一解。

实验单元

from sympy import symbols, Function, dsolve, Eq, exp

t = symbols('t')
N = Function('N')
lam, N0 = symbols('lambda N_0', positive=True)

ode = Eq(N(t).diff(t), -lam * N(t))
sol = dsolve(ode, N(t), ics={N(0): N0})
print(sol)
# 输出: Eq(N(t), N_0*exp(-lambda*t))
