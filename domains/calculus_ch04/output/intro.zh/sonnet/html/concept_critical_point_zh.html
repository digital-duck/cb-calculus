极值点

定义。 设函数 $f$ 在开区间 $I$ 上可微。若某点 $c \in I$ 满足

$$f'(c) = 0$$

或 $f'(c)$ 不存在，则称 $c$ 为 $f$ 的极值点（临界点）。极值点是函数局部极大值或局部极小值的必要候选，但并非所有极值点都对应极值。

几何上，$f'(c)=0$ 意味着曲线 $y=f(x)$ 在 $x=c$ 处的切线为水平线；导数不存在的点（如尖角或竖直切线处）同样需要检验。

例题。 设 $f(x) = x^3 - 3x + 2$，求其所有极值点并判断类型。

第一步：求导并令导数为零。

$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$$

令 $f'(x)=0$，解得 $x=1$ 与 $x=-1$，均为极值点候选。

第二步：用第二导数检验。

$$f''(x) = 6x$$
  • $x=-1$：$f''(-1)=-6<0$，故 $f$ 在 $x=-1$ 处取得局部极大值 $f(-1)=4$。
  • $x=1$：$f''(1)=6>0$，故 $f$ 在 $x=1$ 处取得局部极小值 $f(1)=0$。

    • 关键定理（费马定理）。 若 $f$ 在点 $c$ 处可微，且 $c$ 为局部极值点，则

    $$f'(c) = 0.$$

    证明思路： 不妨设 $c$ 为局部极大值点，则存在 $\delta>0$，对一切 $|h|<\delta$ 有 $f(c+h)\le f(c)$。

    $$\lim_{h\to 0^+}\frac{f(c+h)-f(c)}{h}\le 0, \qquad \lim_{h\to 0^-}\frac{f(c+h)-f(c)}{h}\ge 0.$$

    由于导数存在，两个单侧极限相等，故必有 $f'(c)=0$。$\blacksquare$

    注意：定理的逆命题不成立。$g(x)=x^3$ 在 $x=0$ 处有 $g'(0)=0$，但该点为鞍点（拐点），并非极值。

    实验单元（SymPy）

    from sympy import symbols, diff, solve, latex

x = symbols('x')
f = x**3 - 3*x + 2
fp  = diff(f, x)
fpp = diff(fp, x)

critical_pts = solve(fp, x)
for c in critical_pts:
    val   = f.subs(x, c)
    test  = fpp.subs(x, c)
    kind  = "局部极小" if test > 0 else "局部极大" if test < 0 else "需进一步检验"
    print(f"x = {c}: f(x) = {val}, f''(x) = {test} → {kind}")

    运行后将输出 $x=-1$（局部极大，$f=4$）与 $x=1$（局部极小，$f=0$），与手算结果完全一致。
