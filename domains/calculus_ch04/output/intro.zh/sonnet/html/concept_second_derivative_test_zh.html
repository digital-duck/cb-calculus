Second Derivative Test

定义。 设函数 $f$ 在点 $c$ 处二阶可微，且 $f'(c) = 0$（即 $c$ 为驻点）。二阶导数判别法利用 $f''(c)$ 的符号来判定 $c$ 是极小值点、极大值点还是鞍点：

$$ \begin{cases} f''(c) > 0 & \Rightarrow c \text{ 为严格极小值点，} f(c) \text{ 为局部极小值；} \\ f''(c) < 0 & \Rightarrow c \text{ 为严格极大值点，} f(c) \text{ 为局部极大值；} \\ f''(c) = 0 & \Rightarrow \text{判别法失效，需进一步分析。} \end{cases} $$

几何直觉：$f''(c) > 0$ 表明函数在 $c$ 附近向上弯曲（凹形），如同碗底；$f''(c) < 0$ 表明函数向下弯曲（凸形），如同山顶。

例题。 求函数 $f(x) = x^3 - 3x$ 的所有极值。

解： 首先求驻点：

$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1) = 0 \implies x = 1 \text{ 或 } x = -1.$$

再计算二阶导数：

$$f''(x) = 6x.$$

在 $x = 1$ 处：$f''(1) = 6 > 0$，故 $x=1$ 为极小值点，极小值为 $f(1) = 1 - 3 = -2$。

在 $x = -1$ 处：$f''(-1) = -6 < 0$，故 $x=-1$ 为极大值点，极大值为 $f(-1) = -1 + 3 = 2$。

关键定理（二阶导数判别法）。 设 $f$ 在开区间 $I$ 上二阶连续可微，$c \in I$ 满足 $f'(c)=0$。若 $f''(c) \neq 0$，则

$$f(c) \text{ 为极值} \iff f''(c) \neq 0,$$

且极值类型由 $f''(c)$ 的符号唯一确定。

证明思路： 由泰勒展开，在 $c$ 附近有

$$f(c+h) = f(c) + \underbrace{f'(c)}_{=0}h + \tfrac{1}{2}f''(c)h^2 + O(h^3).$$

当 $|h|$ 足够小时，$O(h^3)$ 项可忽略，故 $f(c+h) - f(c) \approx \tfrac{1}{2}f''(c)h^2$。由于 $h^2 > 0$，差值的符号完全由 $f''(c)$ 决定，从而结论成立。$\blacksquare$

实验单元（SymPy）。

from sympy import symbols, diff, solve, latex

x = symbols('x')
f = x**3 - 3*x
fp  = diff(f, x)
fpp = diff(fp, x)

critical = solve(fp, x)
for c in critical:
    val = fpp.subs(x, c)
    kind = "极小值" if val > 0 else ("极大值" if val < 0 else "失效")
    print(f"x = {c}: f''(x) = {val} → {kind}，f({c}) = {f.subs(x, c)}")

运行后输出 x = -1: 极大值，f(-1) = 2 与 x = 1: 极小值，f(1) = -2，与手算结果完全一致。修改 $f$ 的表达式，可对任意多项式函数进行系统性极值分析。
