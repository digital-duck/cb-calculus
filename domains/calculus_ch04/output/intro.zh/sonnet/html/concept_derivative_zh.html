导数

定义。 设函数 $f$ 在点 $x_0$ 的某邻域内有定义。若极限

$$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$$

存在且有限，则称 $f$ 在点 $x_0$ 可微，并将该极限值称为 $f$ 在 $x_0$ 处的导数（derivative）。几何上，$f'(x_0)$ 即曲线 $y = f(x)$ 在点 $(x_0,\, f(x_0))$ 处切线的斜率；物理上，若 $f(t)$ 表示位移，则 $f'(t)$ 表示瞬时速度。

例题。 求 $f(x) = x^2$ 在 $x_0 = 3$ 处的导数。

按定义展开差商：

$$\frac{f(3+h) - f(3)}{h} = \frac{(3+h)^2 - 9}{h} = \frac{9 + 6h + h^2 - 9}{h} = 6 + h.$$

令 $h \to 0$，得

$$f'(3) = \lim_{h \to 0}(6 + h) = 6.$$

几何验证：曲线 $y = x^2$ 在点 $(3, 9)$ 处的切线方程为 $y - 9 = 6(x - 3)$，即 $y = 6x - 9$。

定理（可微必连续）。 若 $f$ 在 $x_0$ 处可微，则 $f$ 在 $x_0$ 处连续。

证明思路。 将函数增量写成

$$f(x_0 + h) - f(x_0) = \frac{f(x_0+h)-f(x_0)}{h} \cdot h.$$

当 $h \to 0$ 时，右端第一个因子趋向 $f'(x_0)$（有限值），第二个因子 $h \to 0$，故乘积趋向 $0$，即 $\lim_{h\to 0} f(x_0+h) = f(x_0)$，连续性得证。$\blacksquare$

注意逆命题不成立：$f(x) = |x|$ 在 $x = 0$ 处连续但不可微，因为左右极限 $\lim_{h\to 0^-} h/|h| = -1 \neq 1 = \lim_{h\to 0^+} h/|h|$ 不相等。

实验单元（SymPy）。

import sympy as sp

x, h = sp.symbols('x h')
f = x**2

# 用极限定义计算导数
diff_quot = (f.subs(x, x + h) - f) / h
derivative = sp.limit(diff_quot, h, 0)
print(derivative)          # 输出：2*x

# 符号求导验证
print(sp.diff(f, x))       # 输出：2*x

运行上述代码，两种方式均输出 $2x$，与幂函数求导公式 $(x^n)' = nx^{n-1}$（取 $n=2$）完全一致。
