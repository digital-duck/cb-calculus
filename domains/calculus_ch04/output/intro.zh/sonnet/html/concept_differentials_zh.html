微分

定义。 设函数 $y = f(x)$ 在点 $x_0$ 处可导，则称表达式

$$dy = f'(x)\,dx$$

为函数 $f$ 在点 $x$ 处的微分，其中 $dx$ 是自变量 $x$ 的任意增量（称为自变量的微分）。微分 $dy$ 是因变量增量 $\Delta y = f(x+\Delta x)-f(x)$ 的线性主部：当 $\Delta x \to 0$ 时，

$$\Delta y = dy + o(\Delta x),$$

即 $\Delta y - dy$ 是比 $\Delta x$ 高阶的无穷小量。几何上，$dy$ 是曲线在点 $(x, f(x))$ 处切线上的纵坐标增量，而 $\Delta y$ 是曲线本身的纵坐标增量；两者之差随 $\Delta x \to 0$ 而迅速趋于零。

例题。 求函数 $f(x) = x^3 - 2x$ 在 $x = 1$、$dx = 0.01$ 处的微分，并与真实增量比较。

解。 先求导数：$f'(x) = 3x^2 - 2$，故 $f'(1) = 1$。

微分近似值：

$$dy = f'(1)\,dx = 1 \times 0.01 = 0.01.$$

真实增量：

$$\Delta y = f(1.01) - f(1) = \bigl[(1.01)^3 - 2(1.01)\bigr] - (1-2) = 1.030301 - 2.02 - (-1) = 0.010301.$$

误差 $|\Delta y - dy| = 0.000301 = O(dx^2)$，与线性主部的阶估计一致。

关键定理（微分的运算法则）。 若 $u(x)$ 与 $v(x)$ 均可微，则

$$d(u \pm v) = du \pm dv, \quad d(uv) = v\,du + u\,dv, \quad d\!\left(\frac{u}{v}\right) = \frac{v\,du - u\,dv}{v^2}\ (v \neq 0).$$

此外，一阶微分形式不变性保证：无论 $x$ 是自变量还是另一变量的函数，$dy = f'(x)\,dx$ 的形式保持不变，这一性质使得换元积分得以严格成立。

实验单元（SymPy）

from sympy import symbols, diff, Function

x = symbols('x')
f = x**3 - 2*x

dy = diff(f, x)          # 微分系数 f'(x)
print("f'(x) =", dy)
print("dy|_{x=1} =", dy.subs(x, 1))  # 在 x=1 处的值

运行后应输出 f'(x) = 3<em>x</em>*2 - 2 及 dy|_{x=1} = 1，与例题吻合。
