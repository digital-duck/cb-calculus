增长率的本质与意义

在微积分的旅程中，我们从极限出发，历经导数、积分，最终抵达增长率这一核心概念。增长率并非旅程的终点，而是一把万能钥匙——它将抽象的数学语言翻译为现实世界中可观测、可预测的动态规律。形式上，函数 $f(t)$ 在时刻 $t$ 的瞬时增长率定义为导数

$$r(t) = \frac{f'(t)}{f(t)},$$

当 $f(t) = f_0 e^{kt}$ 时，$r(t) = k$ 为常数，称为指数增长率；对于更一般的幂律增长 $f(t) = t^\alpha$，则有 $r(t) = \alpha/t$，随时间衰减，揭示了增长的自我抑制机制。

具体例题

设某种细菌种群数量满足 $P(t) = 500 e^{0.3t}$（$t$ 以小时为单位）。求 $t = 4$ 时的瞬时增长率及种群绝对增长速度。

由定义，$P'(t) = 500 \times 0.3\, e^{0.3t} = 150\, e^{0.3t}$，故

$$r(4) = \frac{P'(4)}{P(4)} = \frac{150\, e^{1.2}}{500\, e^{1.2}} = 0.3 \text{ 每小时},$$

而绝对速度 $P'(4) = 150 e^{1.2} \approx 498$ 个/小时。增长率恒定，绝对速度却随种群规模线性放大，正是指数增长的典型特征。

核心定理

> 比较增长率定理：设 $f, g : [1, +\infty) \to (0,+\infty)$ 均可微。若 > $$\lim_{t \to \infty} \frac{f'(t)/f(t)}{g'(t)/g(t)} = L > 1,$$ > 则 $f(t)$ 最终以比 $g(t)$ 更快的相对速度增长，即 $f(t)/g(t) \to +\infty$。

此定理为函数阶的比较提供了严格的速率语言，超越了大$O$记号的定性描述，给出定量的增长差异。

SymPy 实验室

from sympy import *
t = symbols('t', positive=True)

f = 500 * exp(Rational(3,10) * t)
r = diff(f, t) / f          # 瞬时增长率
print("增长率 r(t) =", simplify(r))

# 比较 e^t 与 t^100 的相对增长率之比
g1, g2 = exp(t), t**100
ratio = simplify((diff(g1,t)/g1) / (diff(g2,t)/g2))
print("增长率之比 =", ratio)
print("极限 t→∞:", limit(ratio, t, oo))

运行上述代码，学生将亲眼看到指数函数的增长率始终压倒任意幂函数——这一结论在算法复杂度分析、种群动力学与金融复利建模中无处不在。
