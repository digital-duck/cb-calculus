Extreme Value Theorem

定义. 设 $f$ 为定义在闭区间 $[a, b]$ 上的连续函数。极值定理（Extreme Value Theorem，EVT）断言：$f$ 在 $[a, b]$ 上必然取得其最大值与最小值，即存在点 $c, d \in [a, b]$，使得对所有 $x \in [a, b]$，均有

$$ f(d) \leq f(x) \leq f(c). $$

此处，$f(c)$ 称为 $f$ 在 $[a, b]$ 上的全局最大值，$f(d)$ 称为全局最小值。定理成立的两个关键条件缺一不可：区间必须有界且闭合，函数必须连续。若去掉任一条件，结论可能失效——例如 $f(x) = x$ 在开区间 $(0, 1)$ 上连续，却无最大值。

例题. 求 $f(x) = x^3 - 3x$ 在 $[-2, 2]$ 上的全局极值。

解： 首先求驻点。令

$$ f'(x) = 3x^2 - 3 = 0 \implies x = \pm 1. $$

两个驻点均属于 $(-2, 2)$，因此候选点为端点与驻点共四处：

| $x$ | $f(x)$ | |-----|--------| | $-2$ | $(-8)+6 = -2$ | | $-1$ | $-1+3 = 2$ | | $1$ | $1-3 = -2$ | | $2$ | $8-6 = 2$ |

比较可得：全局最大值为 $f(-1) = f(2) = 2$，全局最小值为 $f(-2) = f(1) = -2$。

关键定理（证明思路）. 极值定理的严格证明依赖实数完备性。其核心步骤如下：

  • 因 $[a,b]$ 为紧集，$f$ 连续，故 $f([a,b])$ 亦为紧集（连续映射保紧性）。
  • $\mathbb{R}$ 中的紧子集有界且闭合，因而其上确界 $M = \sup_{x\in[a,b]} f(x)$ 属于该集合。
  • 故存在 $c \in [a,b]$ 使 $f(c) = M$；最小值同理可证。$\blacksquare$

    • 实验单元（SymPy）.

    from sympy import *
x = symbols('x')
f = x**3 - 3*x
interval = (-2, 2)

candidates = [interval[0], interval[1]] + solve(diff(f, x), x)
values = {c: f.subs(x, c) for c in candidates if interval[0] <= c <= interval[1]}

print("全局最大值:", max(values, key=values.get), "→", max(values.values()))
print("全局最小值:", min(values, key=values.get), "→", min(values.values()))
