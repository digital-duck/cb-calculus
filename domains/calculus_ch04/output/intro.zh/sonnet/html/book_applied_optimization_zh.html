收益

应用优化是数学分析的自然归宿：它将极限、导数、积分与线性代数的抽象机制，转化为在现实约束下寻找最优决策的具体能力。若将微积分比作语言的语法，则应用优化便是以该语法写就的文学——它赋予工具以意义，赋予定理以目的。

核心思想。 给定目标函数 $f: \mathbb{R}^n \to \mathbb{R}$ 与可行域 $\mathcal{F} \subseteq \mathbb{R}^n$，应用优化研究问题

$$ \min_{\mathbf{x} \in \mathcal{F}}\; f(\mathbf{x}) $$

的存在性、唯一性与计算方法。当 $\mathcal{F}$ 由等式与不等式约束刻画时，Karush–Kuhn–Tucker（KKT）条件给出最优性的必要条件：

$$ \nabla f(\mathbf{x}^*) + \sum_{i} \lambda_i \nabla g_i(\mathbf{x}^*) = \mathbf{0}, \quad \lambda_i \geq 0, \quad \lambda_i g_i(\mathbf{x}^*) = 0. $$

具体示例。 设某工厂以成本函数 $C(x, y) = x^2 + 2y^2 - xy$ 生产两种商品，产量须满足 $x + y = 10$。利用 Lagrange 乘数法，令 $\mathcal{L} = C - \lambda(x+y-10)$，由 $\partial \mathcal{L}/\partial x = 0$ 与 $\partial \mathcal{L}/\partial y = 0$ 联立，解得 $x = \tfrac{20}{3},\; y = \tfrac{10}{3}$，最小成本 $C^* = \tfrac{200}{9} \approx 22.2$。整个求解过程不过是本书前各章技术的一次协同演出。

核心定理（凸优化基本定理）。 若 $f$ 为凸函数且 $\mathcal{F}$ 为凸集，则任意局部极小值即为全局极小值；若 $f$ 严格凸，则全局极小值唯一。

# 实验单元：用 SymPy 验证上述工厂问题
from sympy import symbols, solve, hessian, Matrix

x, y, lam = symbols('x y lambda')
C = x**2 + 2*y**2 - x*y
L = C - lam*(x + y - 10)
sol = solve([L.diff(x), L.diff(y), L.diff(lam)], [x, y, lam])
print(sol)                          # {x: 20/3, y: 10/3, lambda: 10/3}
H = hessian(C, [x, y])
print(H.eigenvals())                # 验证 Hessian 正定，确认极小值

这一工具箱的威力在于其普适性：无论是训练神经网络时对损失曲面的梯度下降，还是结构工程中的最小材料用量设计，乃至经济学中的效用最大化，其数学骨架均为同一张面孔。读者现已站在应用优化的门槛之上。邀请你选择一个你最感兴趣的应用领域，深入探究其背后的优化模型——那里等待着你的，是数学真正改变世界的地方。
