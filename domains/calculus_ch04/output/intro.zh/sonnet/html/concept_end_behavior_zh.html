端行为

定义。 设函数 $f(x)$ 在 $(-\infty, +\infty)$ 上有定义（或在某无界区间上有定义）。若当 $x \to +\infty$ 时 $f(x)$ 趋近于某个有限值 $L$，则称 $L$ 为 $f$ 在正无穷处的水平渐近线，记作

$$\lim_{x \to +\infty} f(x) = L.$$

类似地，若 $\lim_{x \to -\infty} f(x) = M$，则 $y = M$ 为负无穷处的水平渐近线。若上述极限为 $\pm\infty$，则函数无界增长或无界递减，此时称函数在该方向无水平渐近线。函数在 $x \to \pm\infty$ 时的整体表现，统称为函数的端行为（end behavior）。

例题。 分析有理函数

$$f(x) = \frac{3x^2 - 5}{2x^2 + x + 1}$$

的端行为。

将分子分母同除以最高次项 $x^2$：

$$f(x) = \frac{3 - \dfrac{5}{x^2}}{2 + \dfrac{1}{x} + \dfrac{1}{x^2}}.$$

当 $x \to \pm\infty$ 时，所有含 $x$ 的分母项趋于零，故

$$\lim_{x \to \pm\infty} f(x) = \frac{3 - 0}{2 + 0 + 0} = \frac{3}{2}.$$

因此 $y = \dfrac{3}{2}$ 是 $f$ 唯一的水平渐近线，函数从两侧均趋近于该值。

关键定理（有理函数端行为）。 设 $f(x) = \dfrac{a_n x^n + \cdots}{b_m x^m + \cdots}$，$a_n, b_m \neq 0$。则：

  • 若 $n < m$，则 $\displaystyle\lim_{x \to \pm\infty} f(x) = 0$，水平渐近线为 $y = 0$；
  • 若 $n = m$，则 $\displaystyle\lim_{x \to \pm\infty} f(x) = \dfrac{a_n}{b_m}$；
  • 若 $n > m$，则极限为 $\pm\infty$，无水平渐近线（此时可能存在斜渐近线）。

    • 证明思路： 对 $\dfrac{a_n x^n}{b_m x^m} = \dfrac{a_n}{b_m} x^{n-m}$ 取极限，其余低次项在无穷远处可忽略不计。

    SymPy 实验单元。

    from sympy import *
x = symbols('x')

f = (3*x**2 - 5) / (2*x**2 + x + 1)

lim_pos = limit(f, x, oo)
lim_neg = limit(f, x, -oo)

print("x → +∞ 时的极限：", lim_pos)   # 3/2
print("x → -∞ 时的极限：", lim_neg)   # 3/2

# 绘制函数图像以直观验证端行为
plot(f, (x, -50, 50), ylabel='f(x)', title='端行为示例')

    运行后可观察到：图像在两端均趋近于水平线 $y = \dfrac{3}{2}$，与理论结论吻合。
