Rolles Theorem

定义

设函数 $f$ 满足以下三个条件：

  • $f$ 在闭区间 $[a, b]$ 上连续；
  • $f$ 在开区间 $(a, b)$ 上可微；
  • $f(a) = f(b)$。

    • 则存在至少一点 $c \in (a, b)$，使得

    $$f'(c) = 0.$$

    这一结论称为罗尔定理（Rolle's Theorem）。直观上，若一条光滑曲线在两端点处取相同的函数值，则曲线上必存在某处"水平切线"，即导数为零的点。

    证明思路

    由于 $f$ 在 $[a, b]$ 上连续，根据极值定理，$f$ 必在该区间上取到最大值 $M$ 与最小值 $m$。

  • 若 $M = m$，则 $f$ 为常函数，从而 $(a,b)$ 内任意点均满足 $f'(c) = 0$。
  • 若 $M > m$，则最大值或最小值中至少有一个在开区间 $(a,b)$ 内某点 $c$ 处取到。由费马定理，可微函数在内部极值点处导数为零，故 $f'(c) = 0$。$\blacksquare$

    • 具体例题

    题目： 设 $f(x) = x^2 - 4x + 3$，验证罗尔定理在区间 $[1, 3]$ 上成立，并求满足条件的点 $c$。

    解：

    首先检验三个条件：

  • $f$ 为多项式，在 $[1,3]$ 上连续且在 $(1,3)$ 上可微；
  • $f(1) = 1 - 4 + 3 = 0$，$f(3) = 9 - 12 + 3 = 0$，故 $f(1) = f(3)$。

    • 三个条件均满足。对 $f$ 求导：

    $$f'(x) = 2x - 4.$$

    令 $f'(c) = 0$，得

    $$2c - 4 = 0 \implies c = 2.$$

    因 $2 \in (1, 3)$，故 $c = 2$ 即为所求点。

    关键定理

    罗尔定理是拉格朗日中值定理（Lagrange's Mean Value Theorem）的特殊情形，后者将端点等值的限制推广为一般斜率，断言存在 $c \in (a,b)$ 使得

    $$f'(c) = \frac{f(b) - f(a)}{b - a}.$$

    罗尔定理亦是证明该定理的核心工具。

    实验单元（SymPy）

    from sympy import symbols, diff, solve, factor

x = symbols('x')
f = x**2 - 4*x + 3

f_prime = diff(f, x)
critical_points = solve(f_prime, x)

print("f'(x) =", f_prime)
print("满足 f'(c)=0 的点：", critical_points)
print("验证端点值相等：f(1) =", f.subs(x,1), "，f(3) =", f.subs(x,3))
