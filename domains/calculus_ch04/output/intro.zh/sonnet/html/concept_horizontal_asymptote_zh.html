Horizontal Asymptote

定义。 设函数 $f(x)$ 在区间 $(-\infty, +\infty)$ 上（或其某一无界子集上）有定义。若存在常数 $L \in \mathbb{R}$，使得

$$\lim_{x \to +\infty} f(x) = L \quad \text{或} \quad \lim_{x \to -\infty} f(x) = L,$$

则称直线 $y = L$ 为函数 $f(x)$ 的一条水平渐近线（horizontal asymptote）。水平渐近线描述的是：当自变量趋向正无穷或负无穷时，函数值无限接近某一固定水平直线，但未必与之相交。一个函数最多有两条水平渐近线（$x \to +\infty$ 与 $x \to -\infty$ 各一条）。

例题。 求函数

$$f(x) = \frac{3x^2 - 5}{2x^2 + x + 1}$$

的水平渐近线。

解： 分子与分母均为 $x$ 的二次多项式，次数相同。将分子分母同除以 $x^2$：

$$\lim_{x \to \pm\infty} \frac{3x^2 - 5}{2x^2 + x + 1} = \lim_{x \to \pm\infty} \frac{3 - \dfrac{5}{x^2}}{2 + \dfrac{1}{x} + \dfrac{1}{x^2}} = \frac{3 - 0}{2 + 0 + 0} = \frac{3}{2}.$$

因此，$y = \dfrac{3}{2}$ 是 $f(x)$ 在 $x \to +\infty$ 与 $x \to -\infty$ 两个方向上唯一的水平渐近线。

关键定理（有理函数的水平渐近线判别法）。 设 $f(x) = \dfrac{p(x)}{q(x)}$，其中 $p(x)$ 与 $q(x)$ 为多项式，$\deg p = m$，$\deg q = n$。

  • 若 $m < n$，则 $y = 0$ 为水平渐近线；
  • 若 $m = n$，则 $y = \dfrac{a_m}{b_n}$（首项系数之比）为水平渐近线；
  • 若 $m > n$，则不存在水平渐近线（函数趋向无穷）。

    • 证明要点： 将分子分母同除以 $x^{\max(m,n)}$，利用 $\lim_{x\to\infty} x^{-k} = 0$（$k > 0$）即得。

    实验单元（SymPy）

    from sympy import *
x = symbols('x')
f = (3*x**2 - 5) / (2*x**2 + x + 1)

lim_pos = limit(f, x,  oo)   # x → +∞
lim_neg = limit(f, x, -oo)   # x → -∞
print(lim_pos, lim_neg)       # 输出：3/2  3/2

plot(f, (x, -50, 50), title='f(x) 及其水平渐近线 y = 3/2')

    运行上述代码，可在图像中观察到曲线在两端均趋近水平线 $y = \dfrac{3}{2}$，直观验证解析结论。
