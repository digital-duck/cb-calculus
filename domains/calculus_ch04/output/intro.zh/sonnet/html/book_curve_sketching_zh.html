Concept Book: Curve Sketching

Calculus Ch04 · Generated by SPL

收益

曲线描绘是微积分分析的综合体现：给定一个函数 $f(x)$，通过系统地考察其定义域、极限行为、连续性、导数符号及二阶导数符号，在坐标系中精确重建该函数完整几何形态的过程。它不是简单的数值采样，而是将代数信息转化为几何洞见的分析框架。

定义

设 $f: D \subseteq \mathbb{R} \to \mathbb{R}$ 为可微函数。曲线描绘指按以下步骤构建 $y = f(x)$ 图像的系统程序：

  • 确定定义域 $D$ 及所有间断点；
  • 计算水平、竖直与斜渐近线；
  • 以 $f'(x) = 0$ 或不存在处为边界，划分单调区间；
  • 以 $f''(x) = 0$ 或不存在处为边界，划分凹凸区间，并定位拐点；
  • 综合以上信息，绘制精确的定性图像。

    • 典型例题

    考察 $f(x) = \dfrac{x^2 - 1}{x^2 + 1}$。

  • 定义域：$\mathbb{R}$，无间断点。
  • 渐近线：$\lim_{x \to \pm\infty} f(x) = 1$，故 $y = 1$ 为水平渐近线；无竖直渐近线。
  • 单调性：$f'(x) = \dfrac{4x}{(x^2+1)^2}$，故 $x < 0$ 时递减，$x > 0$ 时递增，$x = 0$ 为极小值点，$f(0) = -1$。
  • 凹凸性：$f''(x) = \dfrac{4(1-3x^2)}{(x^2+1)^3}$，拐点位于 $x = \pm\tfrac{1}{\sqrt{3}}$，对应图像凹凸转换。

    • 综合以上信息，可精确刻画该有理函数的完整形态：从 $y=1$ 下方递减至谷底，再对称上升趋近 $y=1$。

    核心定理

    一阶导数判别法：若 $f'(c) = 0$，且 $f'$ 在 $c$ 两侧变号，则 $f(c)$ 为局部极值。二阶导数判别法：若 $f'(c) = 0$ 且 $f''(c) > 0$，则 $f(c)$ 为局部极小值；$f''(c) < 0$ 则为局部极大值。两条定理联合保证：极值点与凹凸区间的判定具有严格的代数依据，而非依赖图形直觉。

    实验单元（SymPy）

    import sympy as sp
x = sp.Symbol('x')
f = (x**2 - 1) / (x**2 + 1)
print(sp.solve(sp.diff(f, x), x))          # 极值候选点
print(sp.solve(sp.diff(f, x, 2), x))       # 拐点候选点
sp.plot(f, (x, -4, 4), ylabel='f(x)')
