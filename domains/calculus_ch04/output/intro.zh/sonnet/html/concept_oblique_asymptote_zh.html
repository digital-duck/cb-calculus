Oblique Asymptote

定义。 设函数 $f(x)$ 在 $(-\infty, +\infty)$ 上（或某无穷区间上）有定义。若存在实数 $k \neq 0$ 与 $b$，使得

$$\lim_{x \to +\infty} \left[ f(x) - (kx + b) \right] = 0 \quad \text{或} \quad \lim_{x \to -\infty} \left[ f(x) - (kx + b) \right] = 0,$$

则称直线 $y = kx + b$ 为 $f(x)$ 的一条斜渐近线（oblique asymptote）。当 $k = 0$ 时退化为水平渐近线，故斜渐近线要求 $k \neq 0$。

确定斜渐近线的标准方法分两步：

$$k = \lim_{x \to \infty} \frac{f(x)}{x}, \qquad b = \lim_{x \to \infty} \left[ f(x) - kx \right].$$

若上述两极限均存在且有限，则 $y = kx + b$ 即为所求斜渐近线。

例题。 求函数 $f(x) = \dfrac{x^2 + 2x - 1}{x - 1}$ 当 $x \to +\infty$ 时的斜渐近线。

解： 首先计算斜率：

$$k = \lim_{x \to +\infty} \frac{f(x)}{x} = \lim_{x \to +\infty} \frac{x^2 + 2x - 1}{x(x-1)} = \lim_{x \to +\infty} \frac{x^2 + 2x - 1}{x^2 - x} = 1.$$

再做多项式除法：$x^2 + 2x - 1 = (x-1)(x+3) + 2$，故

$$f(x) = x + 3 + \frac{2}{x-1}.$$

因此

$$b = \lim_{x \to +\infty} \left[ f(x) - x \right] = \lim_{x \to +\infty} \left( 3 + \frac{2}{x-1} \right) = 3.$$

斜渐近线为 $y = x + 3$。$\blacksquare$

关键定理。 设 $f(x) = \dfrac{P(x)}{Q(x)}$ 为有理函数，其中 $\deg P = \deg Q + 1$。则 $f(x)$ 恰好存在一条斜渐近线，其方程由 $P(x) \div Q(x)$ 的商的线性部分给出；余式对应的分式项趋于零。

实验单元（SymPy）。

from sympy import *
x = symbols('x')
f = (x**2 + 2*x - 1) / (x - 1)

k = limit(f / x, x, oo)
b = limit(f - k*x, x, oo)
print(f"斜渐近线：y = {k}x + {b}")   # 输出：y = 1x + 3

# 验证：多项式除法
q, r = div(x**2 + 2*x - 1, x - 1, x)
print(f"商：{q}，余式：{r}")           # 商：x+3，余式：2
