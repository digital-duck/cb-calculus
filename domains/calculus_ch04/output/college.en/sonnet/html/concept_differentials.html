Differentials

When you compute a derivative $\frac{dy}{dx}$, the symbols $dy$ and $dx$ look like a fraction but are treated as a single object. Differentials give those symbols independent meaning: $dx$ is a small (but finite) change in $x$ that you choose, and $dy$ is the corresponding change in $y$ that the tangent line predicts.

If $y = f(x)$ is differentiable, the differential of $y$ is defined as

$$dy = f'(x)\, dx.$$

This is simply the derivative times your chosen step size. The equation says: if you move $dx$ units along the $x$-axis, the tangent line rises (or falls) by exactly $dy$ units. The actual function changes by $\Delta y = f(x + dx) - f(x)$, which differs from $dy$ only by a tiny error that shrinks to zero much faster than $dx$ does. For small $dx$, $dy \approx \Delta y$, which is the linear approximation you use in practice.

Worked example. Estimate $\sqrt{4.06}$ without a calculator.

Let $f(x) = \sqrt{x}$, so $f'(x) = \frac{1}{2\sqrt{x}}$. Choose the base point $x = 4$ (where the square root is exact) and set $dx = 0.06$.

$$dy = f'(4)\cdot dx = \frac{1}{2\sqrt{4}}\cdot 0.06 = \frac{1}{4}\cdot 0.06 = 0.015.$$

Therefore $\sqrt{4.06} \approx \sqrt{4} + dy = 2 + 0.015 = 2.015$. The true value is $2.01494\ldots$, so the error is less than $0.0001$.

Problem-solving application. Differentials appear throughout applied work whenever you need to propagate uncertainty or estimate sensitivity. Suppose the radius of a sphere is measured as $r = 5$ cm with a possible error of $\pm 0.1$ cm. How much uncertainty does this introduce into the volume $V = \frac{4}{3}\pi r^3$?

Compute $dV$:

$$dV = 4\pi r^2\, dr = 4\pi (25)(0.1) = 10\pi \approx 31.4 \text{ cm}^3.$$

So a $2\%$ error in $r$ ($0.1/5$) produces roughly a $6\%$ error in $V$ ($31.4/523.6$) — matching the rule that a $p\%$ error in radius causes approximately $3p\%$ error in volume, because the exponent is 3. Differentials make that scaling law precise and quantitative without requiring you to evaluate the function at two different radii.
