Concept Book: Locating Absolute Extrema

Calculus Ch04 · Generated by SPL

Payoff

Everything in differential calculus builds toward one practical capability: finding the exact input that makes a function as large — or as small — as possible. Locating absolute extrema is that capability. You have learned how derivatives measure change, how critical points mark where change reverses direction, and how the first and second derivative tests sort local behavior. The absolute-extrema procedure assembles those tools into a complete, finite algorithm.

On a closed interval $[a, b]$, the Extreme Value Theorem guarantees that any continuous function attains both its absolute maximum and absolute minimum. The search is never open-ended: evaluate $f$ at every critical number inside $(a, b)$ and at both endpoints, then compare. The largest value is the global maximum; the smallest is the global minimum. No guessing, no infinite search.

A concrete illustration. A farmer has 120 m of fencing and wants to enclose a rectangular pen along a barn wall, so only three sides need fence. If the side perpendicular to the barn has length $x$, the side parallel to the barn has length $120 - 2x$, giving area

$$A(x) = x(120 - 2x) = 120x - 2x^2, \quad x \in [0,\, 60].$$

Setting $A'(x) = 120 - 4x = 0$ yields $x = 30$. Comparing the three candidates: $A(0) = 0$, $A(30) = 1800\ \text{m}^2$, $A(60) = 0$. The absolute maximum is $\mathbf{1800\ \text{m}^2}$ at $x = 30\ \text{m}$ — a provably optimal answer, not an estimate.

Applied optimization scales this template to every quantitative field. An engineer minimizes the sheet metal in a cylindrical can for a fixed volume. A data scientist minimizes a loss function over model parameters. An economist maximizes profit subject to a budget constraint. A logistics planner minimizes total fuel cost across a delivery network. In every case the recipe is identical: state the objective, encode the constraints, reduce to a function of one variable on a bounded domain, differentiate, and compare the finitely many candidates. The procedure never changes — only the context does.

The most instructive starting point in applied optimization is engineering design: minimizing the material cost of a container with a fixed capacity. That problem forces you to combine a constraint equation with an objective function before a single derivative is taken, and working through it reveals exactly why mastering absolute extrema is the turning point that makes real optimization problems solvable.
