Riemann Sum

A Riemann sum approximates the area between a curve $y = f(x)$ and the $x$-axis over an interval $[a, b]$ by slicing that interval into $n$ subintervals, erecting a rectangle on each slice, and adding up the rectangle areas. If each subinterval has width $\Delta x = \frac{b - a}{n}$, and we choose a sample point $x_i^*$ in the $i$-th subinterval, the Riemann sum is

$$S_n = \sum_{i=1}^{n} f(x_i^*)\,\Delta x.$$

The three standard choices for $x_i^*$ are the left endpoint, right endpoint, and midpoint of each subinterval. As $n \to \infty$ and $\Delta x \to 0$, the sum converges to the definite integral:

$$\int_a^b f(x)\,dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*)\,\Delta x.$$

Worked example. Estimate $\int_0^2 x^2\,dx$ using a right-endpoint Riemann sum with $n = 4$ rectangles.

  • Interval width: $\Delta x = \frac{2 - 0}{4} = 0.5$
  • Right endpoints: $x_1 = 0.5,\ x_2 = 1.0,\ x_3 = 1.5,\ x_4 = 2.0$
  • Rectangle heights (i.e., $f(x_i) = x_i^2$): $0.25,\ 1.00,\ 2.25,\ 4.00$
  • Sum: $S_4 = (0.25 + 1.00 + 2.25 + 4.00)(0.5) = 7.50 \times 0.5 = 3.75$

    • The exact value is $\int_0^2 x^2\,dx = \frac{8}{3} \approx 2.667$. The right-endpoint sum overshoots because $f(x) = x^2$ is increasing — each rectangle extends above the curve. A left-endpoint sum would underestimate for the same reason.

    Problem-solving application. Riemann sums are the basis for numerical integration whenever no closed-form antiderivative exists — for instance, $\int_0^1 e^{-x^2}\,dx$ (the Gaussian integral). To control error, increase $n$: for a right- or left-endpoint sum on a monotone function, the error is bounded by $|f(b) - f(a)|\,\Delta x$, so doubling $n$ halves the error. The midpoint rule converges faster (error $\propto \Delta x^2$), making it the practical default for moderate precision. When you encounter a definite integral numerically, think of the Riemann sum as your ground truth: partition, sample, multiply by width, add. Every quadrature rule — trapezoidal, Simpson's, Gaussian — refines this same idea.
