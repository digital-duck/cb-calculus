Concept Book: Price Demand Application

收获

价格–需求应用将微积分的三条主线——函数极限、导数与积分——汇聚于市场分析这一具体情境之中。至此，我们不再将数学视为抽象符号的演算，而是将其理解为刻画真实经济行为的精确语言。

核心定义回顾。 设商品的需求函数为 $Q = D(p)$，其中 $p$ 为单价，$Q$ 为需求量。市场均衡点 $(p^, Q^)$ 满足 $D(p^) = S(p^)$，其中 $S(p)$ 为供给函数。消费者剩余定义为

$$CS = \int_0^{Q^*} P_d(q)\, dq - p^* Q^*,$$

其中 $P_d(q)$ 为需求的反函数，即消费者愿意为第 $q$ 单位商品支付的最高价格。

具体算例。 设 $D(p) = 100 - 2p$，$S(p) = 3p$。令 $D = S$，解得 $p^ = 20$，$Q^ = 60$。此时

$$CS = \int_0^{60} \frac{100 - q}{2}\, dq - 20 \times 60 = 1800 - 1200 = 600.$$

该数值度量了消费者从市场交易中获得的总福利，是政策分析与定价策略的核心指标。

关键定理。 若需求函数 $D(p)$ 在 $[p_1, p_2]$ 上连续可微，则当价格由 $p_1$ 上升至 $p_2$ 时，消费者剩余的变化量为

$$\Delta CS = -\int_{p_1}^{p_2} D(p)\, dp.$$

此结果直接来自微积分基本定理，将"面积变化"与"价格路径上的积分"精确对应起来。

实验单元（SymPy）。

from sympy import symbols, integrate, solve, Rational
p, q = symbols('p q', positive=True)
D = 100 - 2*p;  S = 3*p
p_star = solve(D - S, p)[0]          # 均衡价格
Q_star = D.subs(p, p_star)           # 均衡数量
Pd_inv = (100 - q) / 2               # 需求反函数
CS = integrate(Pd_inv, (q, 0, Q_star)) - p_star * Q_star
print(f"均衡: p*={p_star}, Q*={Q_star}, CS={CS}")

运行以上代码，可即时验证手算结果，并进一步探索需求弹性对消费者剩余的影响。
