Integration By Substitution

Definition. Let $f$ and $g$ be functions such that $f$ is continuous on the range of $g$, and $g$ is differentiable on an interval $[a, b]$. The method of substitution (also called $u$-substitution) states that

$$\int f(g(x))\, g'(x)\, dx = \int f(u)\, du, \qquad u = g(x).$$

For definite integrals, the limits transform accordingly:

$$\int_{a}^{b} f(g(x))\, g'(x)\, dx = \int_{g(a)}^{g(b)} f(u)\, du.$$

The technique is the integration counterpart of the chain rule: if $F' = f$, then $\frac{d}{dx}F(g(x)) = f(g(x))g'(x)$, so the substitution simply reverses that differentiation.

Worked Example. Evaluate $\displaystyle I = \int x\cos(x^2)\, dx$.

Set $u = x^2$, so $du = 2x\, dx$, which gives $x\, dx = \tfrac{1}{2}\, du$. The integrand transforms as

$$I = \int \cos(u)\cdot \tfrac{1}{2}\, du = \tfrac{1}{2}\sin(u) + C = \tfrac{1}{2}\sin(x^2) + C.$$

Verification: Differentiating $\tfrac{1}{2}\sin(x^2)$ by the chain rule yields $\tfrac{1}{2}\cdot\cos(x^2)\cdot 2x = x\cos(x^2)$. $\checkmark$

Key Theorem. (Substitution Rule for Definite Integrals) If $g'$ is continuous on $[a,b]$ and $f$ is continuous on $g([a,b])$, then

$$\int_{a}^{b} f(g(x))\, g'(x)\, dx = \int_{g(a)}^{g(b)} f(u)\, du.$$

Proof sketch. Let $F$ be an antiderivative of $f$. By the Fundamental Theorem of Calculus, the right-hand side equals $F(g(b)) - F(g(a))$. Applying the chain rule to $F \circ g$ and then invoking the Fundamental Theorem on the left-hand side yields the same quantity.

Lab Cell (SymPy).

from sympy import symbols, cos, integrate, sin, simplify

x, u = symbols('x u')

# Indefinite integral via substitution
expr = x * cos(x**2)
result = integrate(expr, x)
print("Antiderivative:", result)          # sin(x**2)/2

# Definite integral: from 0 to sqrt(pi/2)
from sympy import sqrt, pi
definite = integrate(expr, (x, 0, sqrt(pi/2)))
print("Definite value:", simplify(definite))   # 1/2

The substitution $u = x^2$ collapses the composite structure into a standard $\cos(u)$ form. Choosing the substitution well — identifying an inner function whose derivative appears as a factor — is the central skill the method demands.
